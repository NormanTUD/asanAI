Aha #1 — Ein neuronales Netz ist einfach eine Verkettung affiner Abbildungen mit nichtlinearer Aktivierung

Ein Netz ist NICHT magisch. Es ist: f(x) = Tₗ ∘ g ∘ Tₗ₋₁ ∘ g ∘ … ∘ T₁(x), wo jedes Tᵢ(x) = Wᵢx + bᵢ eine affine Karte und g eine punktweise Nichtlinearität ist.

Was passiert wirklich?

Jede Schicht verzerrt den Raum. Die Nichtlinearität faltet ihn. Nach vielen Schichten kann jede stetige Funktion approximiert werden.

Warum überhaupt Nichtlinearität?

Ohne g ist eine Verkettung von affinen Karten wieder affin — ein einziges großes Wx+b. Erst die Nichtlinearität schafft Ausdruckskraft. Probier's:

Status: Nichtlinear (ReLU)

Aha #2 — Ein einzelnes Neuron ist ein linearer Klassifizierer + Squasher

Ein Neuron rechnet: y = g(w·x + b). Die Hyperebene w·x + b = 0 teilt den Raum. g quetscht das Ergebnis in ein Ausgabeintervall.

Beobachte: Nur die Richtung von w bestimmt die Trennlinie, die Länge von w bestimmt die Schärfe des Übergangs, b verschiebt.

Aha #5 — Backpropagation ist einfach die Kettenregel, mechanisch angewendet

Für y = f(g(h(x))) ist dy/dx = f'(g(h(x))) · g'(h(x)) · h'(x). Backprop propagiert diese Produkte rückwärts durchs Netz.

Warum "rückwärts"?

Vorwärts: berechne Aktivierungen. Rückwärts: multipliziere lokale Ableitungen ansammelnd. Das nennt man Reverse-Mode Automatic Differentiation — effizient wenn wenige Ausgaben (typisch: skalarer Loss) und viele Parameter existieren.

Kosten: Backprop kostet nur ~2-3× so viel wie Forward — unabhängig von der Anzahl der Parameter! Das ist der Grund, warum Deep Learning skaliert.

Aha #6 — Automatic Differentiation: Kategorientheoretisch = Funktor!

AD ist der eindeutige struktur-erhaltende Funktor von der Syntax-Kategorie (Programme) in die Kategorie der Programme mit Ableitungen (CHAD-Perspektive).

Forward-Mode

Berechnet Tangenten vorwärts. Effizient für ℝ → ℝⁿ (wenige Inputs).

Implementiert den Tangentialbündel-Funktor T.

Reverse-Mode (Backprop)

Berechnet Kotangenten rückwärts. Effizient für ℝⁿ → ℝ (viele Inputs, ein Loss).

Implementiert den Kotangentialbündel-Funktor T*.

Aha #7 — Neurale Netze SIND String Diagrams in monoidalen Kategorien

Statt Symbolen: Drähte = Vektorräume (Aktivierungen), Knoten = lineare/nichtlineare Karten. Verkettung = vertikale Komposition. Parallelität = Tensorprodukt (⊗).

Poincaré-Duale

Kommutative Diagramme haben Punkte als Objekte, Pfeile als Morphismen. String-Diagramme drehen das um: Regionen = Objekte, Drähte = Morphismen, Knoten = 2-Morphismen. Dieselbe Info, andere Perspektive!

Aha #8 — Tensor Networks = String Diagrams "mit Haltung"

Ein Tensor Network ist ein String-Diagramm, dessen äußere Drähte einen Zustand im Tensorprodukt kodieren. Verwendet in Quantenphysik, ML, und AdS/CFT.

Verbindung zu Neuralen Netzen

Viele NN-Architekturen (Transformers, CNNs) können als Tensor Networks ausgedrückt werden. Umgekehrt: TNs geben strukturierte, physikalisch motivierte Priors. Aha: Sowohl NNs als auch TNs sind "efficient parametric families of high-dimensional functions/tensors".

Aha #9 — Unendlich breite Netze SIND Gauss-Prozesse (= Quantenfelder!)

Wenn du die Layer-Breite → ∞ schickst, wird das Netz (bei zufälliger Initialisierung) zu einem Gauss-Prozess. Und Gauss-Prozesse sind freie Quantenfelder!

Jede Kurve ist ein zufällig initialisiertes Netz. Bei kleiner Breite sind die Kurven "eigenständig". Bei großer Breite ähneln sie einem glatten stochastischen Prozess (dem NNGP).

Warum ist das ein Aha?

Die "Wahrscheinlichkeitsverteilung über Funktionen", die ein NN darstellt, hat eine Wirkung S[f] = ∫ ρ_f, ähnlich wie in der QFT. Nicht-Gaussianität ↔ Wechselwirkungen. Feynman-Diagramme können auf NNs angewendet werden!

Das nennt sich Neural Network Field Theory.

Aha #10 — Deep Learning ≈ Renormierungsgruppen-Fluss

Frühere Schichten lernen Details (hohe Frequenzen), spätere lernen abstrakte Konzepte (niedrige Frequenzen). Genau wie RG-Flow in der Physik: Coarse-Graining Schicht für Schicht.

Ein Signal (oben) wird schrittweise vergröbert. Jeder RG-Schritt = eine tiefere NN-Schicht. Details verschwinden, aber die Struktur bleibt (bei richtiger Skalierung).

Warum ist das ein Aha?

Mehta & Schwab (2014) haben gezeigt: eine Restricted Boltzmann Machine ist mathematisch äquivalent zu einem RG-Schritt in der Variational RG. Jede Schicht integriert höhere Frequenzen (kurze Skalen) aus und behält relevante niedrige Frequenzen (lange Skalen).

Das erklärt, warum Deep Learning bei natürlichen Daten (Bilder, Sprache, Physik) so gut funktioniert: die Welt ist hierarchisch, und NNs implementieren diese Hierarchie automatisch. [[25]]

Aha #11 — Die Form der Daten zählt: Topologische Sicht

Topological Data Analysis (TDA): Daten haben eine Form (Löcher, Zusammenhangskomponenten, Hohlräume). Diese ist robust gegen Rauschen und oft aussagekräftiger als lokale Metriken.

Persistent Homology

Für ein Datenset baut man eine Filtration von Simplizialkomplexen bei wachsendem Radius ε auf. Für jedes ε: welche Löcher (H₁), welche Komponenten (H₀) existieren?

Persistente Features (die lange „leben") sind echte Struktur; kurzlebige sind Rauschen. [[15]]

Anwendung in Machine Learning

Topological Machine Learning: Persistenz-Diagramme als Feature-Kernels für klassische ML-Modelle. Verbindet Topologie mit Deep Learning. Beispiel: Ein NN kann lernen, mit persistenten Features als Input zu arbeiten, was Robustheit gegen Deformation bringt. [[27]]
