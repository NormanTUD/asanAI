Kapitel 1

Was ist überhaupt ein neuronales Netz?

Ein neuronales Netz ist einfach eine Funktion $f: \mathbb{R}^d \to \mathbb{R}^m$ — die man aus Beispielen lernt, statt sie hinzuschreiben [[11]].

$f(x) = (T_L \circ g \circ T_{L-1} \circ g \circ \dots \circ T_1)(x)$

Was steckt dahinter? Eine Kette von einfachen Schritten:

  • $T_L(x) = \langle W_L, x\rangle + b_L$ — eine affine Abbildung: das Signal wird gewichtet und verschoben.
  • $g$ — eine nichtlineare Aktivierung: verbiegt das Signal (sonst wäre alles nur eine Gerade).
Aha #1: Ein tiefes Netz ist nur eine Sandwich: linear → biegen → linear → biegen → linear. Ohne das "biegen" könntest du 1000 Schichten stapeln und hättest immer noch nur eine Gerade.

Jede Schicht verformt den Raum. Klick den Button und sieh, wie eine Spirale sich entwirrt.

Kapitel 5

Wie ein Netz lernt: Gradientenabstieg

Der nLab-Text nennt es die Kernbewegung [[11]]:

$\theta'(t) = -\nabla_\theta \Phi$ mit $\Phi = \sum_z C(f_{\theta(t)}(z), y_z)$

Übersetzt: Verändere die Parameter $\theta$ in Richtung, in der der Fehler $\Phi$ am schnellsten sinkt.

Epoche: 0

Lernrate η: 0.1
Aha #5: Lernen = Bergabgehen. Man steht auf einer riesigen Berglandschaft (Fehlerlandschaft), berechnet, wo der Boden abfällt, und geht kleine Schritte in diese Richtung. Fertig. Das ist alles.
Aha #6: Zu große Schritte → hüpft übers Tal. Zu kleine → dauert ewig. Deshalb ist die Lernrate $\eta$ der wichtigste Knopf.
Kapitel 6

Die Verlustlandschaft in 3D

Dreh die Kugel. Der rote Pfad ist der Gradientenabstieg — die Bewegung eines Netzes während des Lernens.

Aha #7: Die "$\theta$-Trajektorie" $f_{\theta_i} \mapsto f_{\theta_{i+1}}$ aus dem nLab-Artikel [[11]] ist genau diese rote Kurve. Ein Netz zu trainieren = einen Ball einen Berg herunterrollen lassen.
Aha #8 (fortgeschritten): Im Grenzfall unendlich vieler Parameter wird diese Landschaft so glatt und riesig-dimensional, dass fast überall ein Talweg ist. Das ist die Idee der Neural Tangent Kernel Theory [[11]] — Lernen wird formal ähnlich zur Bewegung eines Teilchens.

Kapitel 8 · Große Netze

Wenn Netze unendlich breit werden

Legt man Gaußsche Zufallsverteilungen über die Gewichte $\theta$ und nimmt die Breite $n \to \infty$, dann folgt aus dem zentralen Grenzwertsatz [[11]]:

Das Netz wird ein Gaußprozess — der NNGP (Neural Network Gaussian Process).

Jede graue Kurve ist ein Netz mit zufällig gewürfelten Gewichten. Bei genügend Neuronen wird die Wolke berechenbar — man weiß im Voraus, wie sie aussieht, ohne zu trainieren.

Aha #10: Ein unendlich breites Netz vor dem Training ist rechnerisch dasselbe wie eine klassische statistische Methode (Kernel-Methode). Deep Learning und "alte" Statistik sind Verwandte — nur an der Grenze.
Aha #11 (nerdig): Die nLab-Seite erwähnt Neural Network Field Theory: hier wird das Netz zu einem Quantenfeld, wenn seine Korrelationsfunktionen die Osterwalder-Schrader-Axiome erfüllen [[11]]. Physik trifft Machine Learning.
Kapitel 9 · Informationsgeometrie

Der Raum aller Wahrscheinlichkeitsverteilungen ist eine Fläche

Informationsgeometrie sagt: Familien von Wahrscheinlichkeitsverteilungen bilden eine Mannigfaltigkeit [[13]]. Beispiel: alle Gauß-Verteilungen $\mathcal{N}(\mu,\sigma)$ leben auf einer 2D-Fläche.

Bewege die Maus — die Kurve zeigt die Verteilung an dieser $(\mu,\sigma)$-Stelle.

Fisher-Metrik: $g(v,w)_s = E_s(v(\log s)\, w(\log s))$

Die Fisher-Information ersetzt "Krümmung", die Kullback-Leibler-Divergenz ersetzt "Abstand" [[13]].

Aha #12: Zwei Verteilungen sind "nah", wenn man sie schlecht voneinander unterscheiden kann. Das ist keine geometrische Nähe — sondern informationstheoretische.
Aha #13: Die Cramér-Rao-Ungleichung — untere Schranke jeder statistischen Schätzung — ist einfach die Aussage: "eine Mannigfaltigkeit ändert sich wenig, wo sie flach ist" [[13]]. Elegant, oder?
Aha #14 (Verbindung): Machine Learning [[12]] + Informationsgeometrie [[13]] + Neuronale Netze [[11]] sind auf nLab derselbe Kontext — Wahrscheinlichkeitstheorie mit Ableitungen. Alles ein einziges großes Gedankengebäude.
