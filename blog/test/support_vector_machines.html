Idee 2 Der Kernel-Trick

Was, wenn die Daten gar nicht geradlinig trennbar sind? Dann hebt man sie in eine höhere Dimension — dort wird aus einem Kreis eine Ebene. Zieh den Regler und beobachte die Magie.

φ(x,y) = (x, y, x²+y²)
→ im 3D-Raum trennt eine flache Ebene

Der Clou: Man muss die Punkte nie wirklich transformieren. Die Kernel-Funktion K(a,b) berechnet das Skalarprodukt im hohen Raum direkt — billig und ohne die Koordinaten je anzufassen.

Krbf(a,b) = exp(−γ‖a−b‖²)
Kpoly(a,b) = (aᵀb + 1)d

Theorie In 4 Schritten

1

Die Hyperebene

Eine Trennfläche wᵀx + b = 0. In 2D eine Gerade, in 3D eine Ebene, darüber eine Hyperebene.

2

Die Margin

Abstand zur nächsten Klasse = 2/‖w‖. Maximieren der Margin heißt also: ‖w‖ minimieren.

3

Soft Margin

Reale Daten überlappen. Schlupfvariablen ξᵢ erlauben Verstöße, C steuert wie teuer die sind.

4

Kernel

Statt Punkte zu transformieren, ersetzt man Skalarprodukte durch K(a,b) — nichtlinear zum Linearpreis.

minw,b,ξ   ½‖w‖² + C·Σᵢ ξᵢ
