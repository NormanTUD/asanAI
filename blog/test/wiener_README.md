# Wiener Archive (flache Kopie)

Diese Kopie liegt im aktuellen Ordner (`blog/test/`) und ist für den direkten
Aufruf neben anderen Testseiten gedacht. Alle Dateien tragen den Prefix
`wiener_`, damit nichts überschrieben wird.

## Öffnen

`wiener_index.html` im Browser öffnen. Die Seiten funktionieren auch per
`file://`; es gibt keinen Server, kein Build, keine externen Skripte.

## Dateien

- `wiener_index.html` — Übersicht
- `wiener_01_cybernetik.html` — Feedback, Regelkreis, Black Box
- `wiener_02_menschliche-nutzung.html` — Information, Entropie, Automation
- `wiener_03_wiener-filter.html` — Signal/Rauschen, Frequenzgewinn, Prädiktion
- `wiener_04_harmonische-analyse.html` — Autokorrelation ↔ Spektrum
- `wiener_05_brownsche-bewegung.html` — Wiener-Prozess, weißes Rauschen, Chaos
- `wiener_06_gott-und-golem.html` — Lernen, Selbstreproduktion, Ethik
- `wiener_07_leben.html` — Zeitleiste, Einflussnetz, Autobiografien
- `wiener_08_regal.html` — weitere Werke und Lesepfad
- `wiener_assets/` — CSS, JS und Porträt
- `wiener_README.md` — diese Datei

Die vollständige Bibliothek mit den Open-Access-Bänden (PDF/EPUB) liegt
weiterhin unter `~/ebooks/wiener/` (siehe `~/ebooks/wiener/quellen/`).

## Quellen

Die Zitate stammen aus den in `~/ebooks/wiener/quellen/` liegenden
MIT-Press-Open-Access-Ausgaben bzw. aus *The Human Use of Human Beings*
(Houghton Mifflin, 1950). Die externe Quellenliste steht auf
`wiener_08_regal.html`.
