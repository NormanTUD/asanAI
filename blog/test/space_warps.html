0Die Frage & die Motivation

Neuronale Netze können irgendwelche Funktionen approximieren — aber wie genau? Welches eine geometrische Werkzeug benutzt ein Feed-Forward-Netz, um Klassen trennbar zu machen?

Konkretes Problem

Bilder von Katzen und Hunden liegen als hochdimensionale Punktwolken vor. Ein linearer Klassifikator ist bloß eine Hyperebene — die reicht selten. Wie schafft es ein tiefes Netz, dass am Ende doch eine Ebene ausreicht?

Antwort in einem Satz

Jede Schicht faltet die Datenmannigfaltigkeit in eine unbenutzte höhere Dimension. Nach genügend Falten liegen die Klassen so, dass eine flache Ebene sie schneidet — wie ein Fold & Cut-Origami.

1Grundbaustein: Was macht eine Schicht?

Eine Schicht = Affine Abbildung (Dreh/Skaliere/Verschiebe) + elementweise Nichtlinearität (z. B. ReLU).

Spiele mit einer Schicht (2D → 2D)

Inputnach Affinnach ReLU

Was zu sehen ist

  • Affin allein zieht Linien zu Linien — Trennbarkeit ändert sich nicht.
  • ReLU „drückt" alles auf negativer Seite einer Hyperebene auf Null — wie ein Hammer, der eine flache Delle macht.
  • Die Kombination positioniert die Daten geschickt und schlägt dann zu.
Variablen
  • W = Gewichtsmatrix (rotiert/skaliert/schert)
  • b = Bias (verschiebt)
  • Φ = Aktivierungsfunktion, hier ReLU(x)=max(0,x)

2Warum Affin allein nicht reicht

Eine affine Abbildung ist ein Homöomorphismus: sie zerreißt nichts. Was innen war, bleibt innen. Nur die Nichtlinearität kann die Topologie „aufbrechen".

Homöomorphismus-Demo

Zwei ineinander verschlungene Spiralen. Ziehe t: siehst du, dass tanh die Spiralen entwirrt, während affin allein sie nur dreht?

Merksatz

Wenn Klasse A von Klasse B umschlossen ist, bekommt man das mit reinen Drehungen/Streckungen niemals auseinander. Man braucht entweder mehr Dimensionen (Falten) oder eine Nichtlinearität, die Punkte kollabiert.

1 · Motivation — Welches Problem lösen die Autoren?

Neuronale Netze können jede Funktion approximieren. Aber wie genau bauen sie eine Klassifikation? Was ist das mechanistische Werkzeug, mit dem eine Datenverteilung so umgeformt wird, dass am Ende eine einzige Hyperebene die Klassen trennt?

Das konkrete Problem

Betrachte zwei Klassen im 2D: einen roten Kreis innen, einen blauen Ring außen. Kein Lineal kann sie trennen. Was tut ein Netz?

2D-Egg-Problem
innen (Klasse A)außen (Klasse B)

Die Kernfrage

  • Ein Netz muss die Datenverteilung schichtweise so verbiegen, dass am Ende eine Hyperebene die Klassen trennt.
  • Welche Grundoperationen stehen einer Schicht dazu zur Verfügung?
  • Welche davon ist am effizientesten, und warum brauchen wir manchmal breite Schichten?

These: Die primäre Operation ist Falten — wie Origami, nur in vielen Dimensionen.

2 · Baustein einer Schicht — Affin dann Nicht-linear

Jede Schicht macht genau zwei Dinge: erst eine affine Transformation (Matrix + Verschiebung), dann eine elementweise Nicht-Linearität (hier ReLU).

Was macht die affine Abbildung?

Sie dreht, skaliert, verschiebt, schert. Aber: Linien bleiben Linien. Sie kann keine lineare Trennbarkeit erzeugen — sie positioniert die Daten nur.

Was macht ReLU? Der „Hammer“

ReLU projiziert alle Punkte mit negativer Voraktivierung auf 0. Man kann das als Ecke eines N-dimensionalen Raums denken, in die die Daten gedrückt werden.

3 · Der Hammer trifft die Verteilung

Jedes Neuron definiert eine Hyperebene (Normale = Gewichtsvektor, Versatz = Bias). Alle Punkte auf der negativen Seite werden auf diese Ebene gedrückt. Ziehe den Regler und schau, wie ein Hammerschlag eine Delle in die 2D-Verteilung schlägt.

Wichtig: Der Hammer verändert nur die konvexe Hülle. Punkte im Inneren einer Klasse (z. B. der rote Kern) sind so nicht erreichbar. Genau hier scheitert die naive Idee.

4 · Kreis-im-Kreis ist nicht linear trennbar — bis man eine Dimension dazunimmt

Im 2D kannst du keine Gerade zeichnen, die den roten Kern vom blauen Ring trennt. Aber wenn du geschickt in die dritte Dimension hebst, wird der Kern angehoben — und plötzlich reicht eine Ebene.

2D-Ansicht (unmöglich mit Gerade)

3D-Lift — bewege den Regler!

Die Regel: In einer höheren, ungenutzten Dimension kann eine Falte den inneren Rand des roten Kreises nach außen kippen. Genau das ist die Origami-Idee.

5 · Falten in ungenutzte Dimensionen — der zentrale Trick

Wenn die Datenmannigfaltigkeit (z. B. eine Linie im 2D) weniger Dimensionen belegt als die Schicht breit ist, dann wird ein ReLU-Hammer, dessen Normale in die freie Dimension zeigt, zu einer Falte statt einer Quetschung. Dies ist injektiv — es geht keine Information verloren!

Eindimensionales „Ei“ wird in 2D gefaltet

Nach der Faltung ist die vorher innere Region an der Kante freigelegt — eine Gerade in der nächsten Schicht kann sie trennen.

2D-Ei mit 3 Neuronen lösen (Abbildung 2 des Papers)

Drei Hyperebenen falten das flache Ei in eine dreieckige „Wanne“ im 3D. Eine Ebene trennt dann innen vom außen.

Mit mehr Neuronen wird die Approximation runder — von Dreieck über Sechseck bis zu einem N-gon, das den Kreis annähert.

6 · Fold-and-Cut — Origami trifft neuronale Netze

Für 10-Jährige erklärt: Nimm ein Blatt Papier. Zeichne irgendeine Form drauf — ein Herz, einen Stern, deinen Namen als Umriss. Behauptung (Demaine, 1998): Du kannst das Papier immer so falten, dass ein einziger gerader Scherenschnitt genau diese Form ausschneidet.

Interaktives Papier-Falten

Tipp: Klicke „zum Ausdrucken“ und probiere es mit echtem Papier & Schere aus — von 2D-Form wird durch Falten und einen Schnitt tatsächlich 3D-Falzstruktur → 2D-Form.

Warum das für neuronale Netze wichtig ist

  • Die letzte Schicht des Netzes macht einen „geraden Schnitt“ — eine Hyperebene.
  • Die vorherigen Schichten falten die Datenverteilung so, dass alle Klassengrenzen aufeinander liegen.
  • Das erklärt die Universal-Approximation: Beliebige Klassen können durch Falten + Schnitt getrennt werden.
  • Analog: Jede piecewise-lineare Entscheidungsgrenze im Original entspricht einer Serie von Falten in höheren Dimensionen.

7 · Alternative (aber ineffizient): Scheren in schmalen tiefen Netzen

Ohne Extra-Dimensionen bleibt nur ein Trick: durch geschicktes Kombinieren von schiefen Hyperebenen (Scherung) und ReLU wird Wahrscheinlichkeitsmasse Schritt für Schritt zur Seite geschoben. Das braucht sehr viele Schichten und skaliert schlecht in höhere Dimensionen.

→ In der Praxis nutzen echte Netze diesen Mechanismus kaum. Das Falten in freie Dimensionen ist viel mächtiger.

8 · Vorhersage bestätigen: Bimodale Tuning-Kurven im Poker-Hand-Netz

Wenn Falten das primäre Werkzeug ist, dann müssen Neuronen an einer Faltkante bimodale Tuning-Kurven zeigen: für manche Klassen zwei Peaks, mit Tal an der Faltposition x̃ = 0. Genau das finden die Autoren im trainierten Netz.

Untrainiertes Netz (fast Gauß-förmig)

Trainiert (bimodal — Zeichen einer Falte!)

Untrainiert: Aktivierungen sehen zufällig-glockenförmig aus. Trainiert: Klasse 2 (dunkelorange) zeigt zwei Peaks mit einem Tal bei x̃ = 0 — genau der Fingerabdruck einer Faltkante. Neurone mit großer „Dip-Statistik“ sind auch die wichtigsten: Wenn man 10 davon abschaltet, bricht die Genauigkeit massiv ein [[11]].

9 · Die Antwort auf die Frage der Autoren

Die Frage war: Welches mechanistische Werkzeug nutzt ein Feedforward-Netz, um lineare Trennbarkeit herzustellen?

Kurzantwort

  • Progressives Falten der Datenmannigfaltigkeit in ungenutzte höhere Dimensionen.
  • Jede Schicht fügt Falten hinzu → hierarchische Struktur mit exponentiell vielen Kanten.
  • Die letzte Schicht macht einen einzigen „Schnitt“ (Hyperebene) — analog zum Fold-and-Cut-Theorem.
  • Scheren ohne Extra-Dimensionen ist möglich, aber ineffizient und braucht sehr tiefe schmale Netze.
  • Empirisch bestätigt durch bimodale Tuning-Kurven im Poker-Hand-Netz.

Konsequenzen

  • Schichten müssen breiter sein als die Datendimensionalität, sonst kein Falten möglich.
  • Erklärt, warum tiefe, schmale Netze keine universellen Approximatoren sind (Johnson 2018) [[11]].
  • Neuronen mit „mixed selectivity“ sind kein Bug, sondern ein notwendiges Feature des Faltmechanismus — relevant auch für die Neurowissenschaft [[11]].
