01 · Kan-Erweiterungen einfach

Die beste Art, eine Tabelle aufzufüllen

Stell dir vor, du hast Werte auf einer kleinen Menge C und eine Abbildung G: C → D in eine größere Menge. Du willst die Werte auf ganz D ausdehnen. Es gibt viele Möglichkeiten. Die linke Kan-Erweiterung ist die beste: Sie erfindet nichts, sie fasst die Werte entlang der Fasern zusammen.

Konkret: Fünf Items, fünf Werte. Eine Gruppierung f ordnet jedes Item einer Gruppe zu. Die linke Kan-Erweiterung von φ entlang f ist die Summe der Werte pro Gruppe. In Set wäre es die Vereinigung (ein Kolimes), in einer Ordnung das Supremum, in Zahlen mit Addition die Summe.

Die universelle Eigenschaft macht „beste“ präzise: Jede andere gruppenweise Zuweisung, die mit den Einzelwerten verträglich ist, faktorisiert eindeutig durch die Kan-Erweiterung. Es gibt also keinen vernünftigen Weg daran vorbei.

Die formale Definition

Gegeben seien Funktoren G: C → D und K: C → E. Eine linke Kan-Erweiterung von K entlang G ist ein Funktor LanG K: D → E zusammen mit einer natürlichen Transformation η: K ⇒ (LanG K)∘G, sodass es für jedes andere Paar (H: D → E, γ: K ⇒ H∘G) genau eine natürliche Transformation α: LanG K ⇒ H gibt mit γ = (α∘G)η.

In angereicherten Kontexten ist LanG K(d) ein Kolimes über die Komma-Kategorie der Paare (c, G(c) → d). In Set ist das die Vereinigung der Bilder; in einem numerischen Monoid die Summe; in einer Ordnung das Supremum. Die rechte Kan-Erweiterung ist dual: Sie nimmt das Produkt beziehungsweise das Infimum.

Die universelle Eigenschaft ist der Grund, warum die Kan-Erweiterung „die beste“ Ergänzung ist: Jede andere Ergänzung, die auf C mit K übereinstimmt, muss durch sie hindurch. Sie ist der universelle Empfänger aller verträglichen Ergänzungen.

Die Intuition: Eine Kan-Erweiterung ist kein beliebiges Auffüllen. Sie ist das Auffüllen, das aus den vorhandenen Werten und den Verbindungen zwischen ihnen erzwungen wird.
02 · Fehler als Informationsverlust

Was eine Transformation verliert

Das Paper definiert Fehler nicht als Abstand zwischen zwei Ausgaben, sondern als Eigenschaft einer Transformation zwischen Datensätzen. Ein S-flavoured error ist ein laxer 2-Funktor Err: D → S in eine monoidale Präordnung S mit einem Bottom-Element. S sagt, wie Fehler verglichen und kombiniert werden.

Die Schlüsselungleichung ist Err(g) · Err(f) ≤ Err(g ∘ f). Der Fehler einer Komposition ist also mindestens so groß wie die Kombination der Einzelfehler. Im Beispiel S = R∧ (Maximum, übliche Ordnung) heißt das: Err(g∘f) ≥ max(Err(g), Err(f)).

Ein Funktor wäre zu streng. Zwei Transformationen können dieselbe Information verlieren, dann ist der Gesamtverlust nicht viel größer als der größte Einzelverlust. Oder sie verlieren verschiedene Information, dann ist er größer. Die lax-2-functorale Ungleichung fängt beides ein.

Überlappen sich die Verluste, bleibt der Gesamtverlust beim Maximum. Sind sie disjunkt, addieren sie sich. Die Ungleichung gilt in beiden Fällen.
Der lax-2-functorale Fehler
Err(g) · Err(f) ≤ Err(g ∘ f)
Fehler ist eine Eigenschaft der Transformation. Aus dem Bottom-Element und der laxen Komposition wird eine Präordnung auf Datenpaaren.
Die Folge: Abstand, Genauigkeit und Informationsverlust sind nach dieser Sicht Maße dafür, wie viel Transformation nötig ist, um einen Datensatz in einen anderen zu überführen. Der Fehler hängt von der Struktur der Datensätze ab, nicht nur von ihren Werten.
03 · Adjungiert = Minimierer

Die linke Adjungierte ist der beste Agent

Ein kategorientheoretisches Fehlerminimierungsproblem besteht aus Modellen M, Datensätzen D, einer Inferenzabbildung Inf: M → D, einem Fehler auf D und einem Ziel d ∈ D. Gesucht ist ein Modell, dessen Inferenz möglichst nahe an d liegt.

Der erste Hauptsatz des Papers: Hat Inf eine linke Adjungierte Alg: D → M, dann ist Alg(d) für jedes d ein globaler Fehlerminimierer. Die linke Adjungierte ist die beste „Pseudo-Inverse“ zur Inferenz. Bemerkenswert ist, dass das Ergebnis nicht von der konkreten Wahl des Fehlers abhängt: Die Struktur der Kategorie bestimmt den Minimierer.

Das einfachste Bild ist die Inklusion der ganzen Zahlen in die reellen Zahlen. Ihre linke Adjungierte ist die Abrundung. Für ein Ziel d ist floor(d) die beste Approximation von unten: Jede ganze Zahl m mit m ≤ d ist auch ≤ floor(d).

04 · Kan = Minimierer

Die universelle Erweiterung als Lösung

Das Paper formt das Problem als Erweiterungsdreieck: Ein Morphismus ι: δ → μ und ein Objekt τ induzieren durch Präkomposition den Funktor T(ι, τ): T(μ, τ) → T(δ, τ). Das ist genau die Inferenz Inf. Die linke Kan-Erweiterung Lanι d ist dann, wenn sie existiert, ein globaler Fehlerminimierer.

Der Repräsentationssatz (Theorem 4.1) geht weiter: Zu jedem mengentheoretischen Fehlerminimierungsproblem gibt es eine 2-Kategorie T, in der M = T(μ, τ), D = T(δ, τ) und Inf = T(ι, τ) gilt, und ein Modell m ist genau dann ein globaler Minimierer, wenn m ≅ Lanι d. Jedes Fehlerminimierungsproblem ist also eine Kan-Erweiterung.

Die zwei Ergebnisse

Der Repräsentationssatz: Das ist keine Analogie. Zu jedem mengentheoretischen Fehlerminimierungsproblem gibt es eine 2-Kategorie, in der die linken Kan-Erweiterungen genau die globalen Minimierer sind. Wenn kein Minimierer existiert, existiert auch keine Kan-Erweiterung.
05 · Was das heißt

Drei Konsequenzen

Fehler

Fehler ist Transformation

Abstand, Genauigkeit und Informationsverlust sind Maße dafür, wie viel Transformation nötig ist, um einen Datensatz in einen anderen zu überführen. Der Fehler hängt an den Morphismen, nicht nur an den Ausgaben.

Algorithmen

Lernen als Pseudo-Inverse

Wenn Algorithmen die linke Adjungierte zur Inferenz sind, dann ist Lernen das beste Zurückrechnen von Daten auf Modelle. Adjungierte funktionieren in jeder 2-Kategorie, nicht nur in Funktorkategorien.

Erweiterung

Modelle erweitern Daten

ML-Modelle finden Muster und dehnen sie auf neue Daten aus. Genau dieses Ausdehnen ist die Struktur einer Kan-Erweiterung. Annahmen wie Linearität, Glattheit oder Maximum Likelihood sagen, wie erweitert wird.

Grenze

Kein Trainingsalgorithmus

Das Paper ist ein Repräsentationssatz, kein neuer Optimierer. Es sagt, dass jedes Fehlerminimierungsproblem diese Form hat; es sagt nicht, wie man die Kan-Erweiterung effizient berechnet.

Die Einordnung: Das Ergebnis ist ein Brückensatz zwischen Kategorientheorie und maschinellem Lernen. Es öffnet die Tür, Werkzeuge über Kan-Erweiterungen für ML-Probleme zu nutzen. Es ist kein Benchmark und kein empirischer Vergleich.
Die drei Punkte der Schlussfolgerung

1. Fehler als Verlust. Die S-flavoured error legt nahe, Fehler an Transformationen zwischen Datensätzen zu binden. Distance, accuracy und information loss werden zu Maßen der minimalen Transformation, die einen Datensatz in einen anderen überführt.

2. Unabhängigkeit von der Fehlerwahl. Die linke Adjungierte hängt nicht von der konkreten Fehlerfunktion ab. Das legt nahe, dass es fundamentalere Wege gibt, ein global optimales Modell zu wählen. Algorithmen werden zu Pseudo-Inversen der Inferenz; Adjungierte gibt es in jeder 2-Kategorie, also auch für Mannigfaltigkeiten oder Maßräume.

3. Lernen als Erweiterung. ML-Modelle „extend“ Daten: Sie nehmen einen Aspekt der Daten und dehnen ihn auf einen neuen Kontext aus. Genau diese Struktur kodiert eine Kan-Erweiterung. Annahmen wie Linearität, Distanz, Glattheit oder Maximum Likelihood sind die zusätzlichen Annahmen, die diese Ausdehnung möglich machen.

Die Begriffe

Kategorie

Funktor

Eine Familie von Morphismen, die zwei Funktoren verträglich verbindet.
2-Kategorie
Eine Kategorie mit 2-Morphismen zwischen 1-Morphismen. Cat ist das Standardbeispiel.
Adjunktion
Ein Paar von Funktoren L ⊣ R mit Einheit und Koinheit, die zueinander pseudo-invers sind.
Linke Adjungierte
Der linke Partner L einer Adjungierten. Im Text: Alg ⊣ Inf.
Kan-Erweiterung
Die beste Erweiterung eines Funktors K entlang eines Funktors G, definiert durch eine universelle Eigenschaft.
Kolimes
Ein universeller „Zusammenklebe“-Prozess. In Set: Vereinigung; in Zahlen: Summe; in einer Ordnung: Supremum.
Monoidale Präordnung
Eine Präordnung mit einem Tensorprodukt. Werte von Fehlern werden hier verglichen und kombiniert.
Laxer 2-Funktor
Ein 2-Funktor, bei dem die Komposition nur eine Vergleichsrichtung hat: F(g)F(f) ≤ F(gf).
S-flavoured error
Ein laxer 2-Funktor Err: D → S. Er ordnet jeder Datentransformation einen Fehler zu.
Komma-Kategorie
Die Kategorie der Paare (c, G(c) → d). Ihr Kolimes ist die allgemeine Formel für LanG K(d).
Universelle Eigenschaft
Eine Charakterisierung durch „für jede andere Lösung gibt es genau einen Pfeil“. Sie macht „beste“ präzise.
