20 visual atoms

The atoms of computer science.

Twenty foundations from theoretical and practical computer science, each one visual, interactive and reducible to a single idea: a state, a bit, a rewrite, a comparison, a hash, a path, a table, a lock. The goal is the same as in the LLM atoms page: not a tour of topics, but the smallest set of objects from which the rest is built.
