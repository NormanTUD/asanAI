Propositions als Typen — zum Anfassen

Ein Typ ist ein Raum. Ein Beweis ist ein Punkt. Eine Typfamilie ist eine Faserung. Σ ist der Totalraum, Π der Raum der Sektionen. Klick dich durch — alles ist interaktiv.

Das Wörterbuch Table 1, HoTT Book

Drei Lesarten derselben Syntax. Fahr über eine Zeile — die Spalten leuchten synchron.

Die drei interessanten Zeilen: B(x) = Faserung, Σ = Totalraum, Π = Raum der Sektionen. Daraus folgt alles andere — besonders, warum ∀ stärker ist als „für jedes gibt's einen".

Ein Typ ist ein Raum Punkte = Beweise

Klick in die Boxen, um Punkte zu setzen. 𝟘 lässt sich nicht befüllen — es hat keine Konstruktoren.

𝟘 ist unbewohnbar → ⊥. 𝟙 hat genau einen Punkt → ⊤. Alles andere ist eine Proposition, die *mehrere* Beweise haben kann — und genau das ist der Bruch mit klassischer Logik.

A + B ist das „oder" coproduct

Zwei disjunkte Kopien, nebeneinander. Die Konstruktoren inl und inr schieben Punkte hinein. Nichts vermischt sich.

A B A+B
Warum das „oder" ist: Um A+B zu *benutzen*, musst du eine Fallunterscheidung machen — genau die ∨-Eliminationsregel. Um es zu *bauen*, brauchst du einen von beiden — die ∨-Introduktionsregel.

Aber: Das Induktionsprinzip ist „proof by case analysis, which characterizes the disjoint union" [[11]]. Ein Element von A+B weiß, welcher Zweig es war. Klassisches „oder" vergisst das.
Darum gibt's die Truncation. ‖A+B‖ vergisst den Zweig. Das Buch: P ∨ Q :≡ ‖P+Q‖ [[11]]. 𝟙+𝟙 = 𝟐 ist keine Proposition — es hat zwei *unterscheidbare* Punkte [[11]].

Typfamilien sind Faserungen B : A → 𝒰

Zieh die Maus über die Basis A. Die Faser B(x) wandert mit. Jede Faser ist ein eigener Raum.

Zentrale Pointe: Eine Typfamilie ist ein Prädikat P(x) *und* gleichzeitig eine Faserung über A. Faser bewohnt ⟺ Prädikat gilt.

Bei „teilweise leer" siehst du: wo die Faser verschwindet, gilt P(x) nicht. Darum kann es dort keine durchgehende ∀-Sektion geben.
Transport. Ein Pfad p : x = y in der Basis liefert p* : P(x) → P(y) [[11]]. Das ist der Satz „equals may be substituted for equals" — aber jetzt als stetige Bewegung entlang der Faserung.

Σ ist der Totalraum = Existenz ∃

Klick in die Fasern. Jeder Punkt ist ein Paar (a, p): Zeuge + Beweis. Rechts siehst du den Totalraum als eigenen Raum.

Das Buch: „we think of a type family P : A → 𝒰 as a fibration with base space A, with P(x) being the fiber over x, and with Σ(x:A) P(x) being the total space of the fibration" [[11]].

Ein Punkt im Totalraum = Position in A + Höhe in der Faser darüber. Das ist exakt die konstruktive Lesart von „es gibt ein x mit P(x)": du musst den Zeugen mitliefern.
Achtung — dasselbe Truncation-Problem. Σ erinnert sich an den Zeugen. Das Buch: „if we have an inhabitant of Σ(x:A) P(x), regarded as a witness of 'there exists x:A such that P(x)', then we know what the element x is (it is the first projection of the given inhabitant)" [[11]].

Deshalb ist das propositionale ∃ die Truncation: ∃(x:A).P(x) :≡ ‖Σ(x:A) P(x)‖ [[11]].
Und genau deshalb ist das Auswahlaxiom „trivial wahr". Theorem 2.15.7 [[11]] sagt:
Π(x:X) Σ(a:A(x)) P(x,a) ≃ Σ(g:Π(x:X) A(x)) Π(x:X) P(x,g(x))
Links: „für alle x existiert a mit P(x,a)". Rechts: „es gibt eine Auswahlfunktion g". Diese sind äquivalent — kein Axiom nötig! Denn die Wahl war schon in den Daten enthalten; wir packen sie nur um.

Π ist der Raum der Sektionen = ∀ ∀

Eine Sektion wählt stetig einen Punkt in jeder Faser. Zieh am Slider — die Sektion bleibt immer durchgehend. Bei einer Lücke reißt sie ab.

Das Buch: „we may refer to a dependent function f : Π(x:A) P(x) as a section of the fibration P" [[11]].

Warum ist das stärker als „für jedes x gibt's ein Element"? Weil die Zuordnung eine Funktion sein muss — und Funktionen in der Typentheorie sind automatisch „stetig": sie respektieren Pfade. Wenn zwei Basispunkte durch einen Pfad verbunden sind, müssen die zugeordneten Faserelemente durch einen dependent path verbunden sein.
Π bewahrt mere propositions (Example 3.6.2 [[11]]):
isProp(P(x)) für alle x ⟹ isProp(Π(x:A) P(x))
Deshalb ist ∀ „harmlos": keine Truncation nötig.

Daraus folgt sofort: ¬A :≡ (A → 𝟘) ist stets eine mere proposition, da 𝟘 eine ist.

Negation: A → 𝟘 ¬A

Links ein bewohnter Typ A, rechts der leere Typ 𝟘. Versuch, eine totale Funktion zu bauen — es scheitert, solange A Punkte hat.

Deine Frage, präzisiert. Du schreibst „jeder Funktor a : A → 0 ist äquivalent zu der Aussage dass ¬a". Zwei Korrekturen:

(1) Es ist eine Funktion, kein Funktor. Funktoren sind in Kapitel 9 des Buches etwas anderes (zwischen Präkategorien) [[11]].

(2) Es ist nicht „äquivalent zu" — es ist die Definition: ¬A :≡ A → 𝟘 [[11]]. Es gibt keine separate Negation in der Typentheorie.
Warum kann es keine solche Funktion geben, wenn A bewohnt ist? Hättest du a : A und f : A → 𝟘, so wäre f(a) : 𝟘. Aber 𝟘 hat keine Konstruktoren — es ist unbewohnbar. Widerspruch.

Das Buch formuliert die Konstruktionsrichtung: „a witness of ¬A is a function A → 𝟘, which we may construct by assuming x : A and deriving an element of 𝟘" [[11]].
Konstruktiver Widerspruchsbeweis ist okay! Das Buch betont: „this sort of 'proof by contradiction' (assume A and derive a contradiction, concluding ¬A) is perfectly valid constructively: it is simply invoking the meaning of 'negation'" [[11]].

Nicht erlaubt: ¬A annehmen, Widerspruch herleiten, A folgern. Das liefert nur ¬¬A, und es gibt „no obvious way to get from ¬¬A (that is, from (A → 𝟘) → 𝟘) to A" [[11]].
Aber ¬¬¬A → ¬A gilt! (Exercise 1.11 [[11]].) Negation ist auf Negationen „stabil".

Die Truncation-Leiter n-Typen

Jede Stufe hat weniger Struktur als die darüber. Klick auf eine Stufe.

Definition (rekursiv), Definition 7.1.1 [[11]]:
is-n-type(X) :≡ │ isContr(X) // n = −2 │ Π(x,y:X). is-(n−1)-type(x =ₓ y) // n = n′+1
Die Leiter ist aufwärts geschlossen: „if X is an n-type then X is also an (n+1)-type" (Theorem 7.1.7 [[11]]).
Die Leiter ist nicht degeneriert. Das Universum 𝒰 ist keine Menge (Example 3.1.9 [[11]]). Der Beweis: die Nichtidentitäts-Äquivalenz f : 𝟐 ≃ 𝟐 liefert via Univalenz einen Pfad p : 𝟐 = 𝟐. Wäre p = refl, so wäre f = id, also 0₂ = 1₂ — Widerspruch [[11]].

Und Sⁿ⁺¹ ist kein n-Typ (Corollary 8.6.18 [[11]]).

Warum naives „propositions as types" scheitert Thm 3.2.2

Die naive Form von LEM ist inkonsistent mit Univalenz. Hier der Mechanismus, animiert.

Theorem 3.2.2 [[11]]: „It is not the case that for all A : 𝒰 we have ¬(¬A) → A."

Beweisidee: Angenommen f : Π(A:𝒰) (¬¬A → A). Jede Funktion in der Typentheorie ist „stetig", also natürlich bzgl. Äquivalenzen. Nimm e : 𝟐 ≃ 𝟐 die Vertauschung, p :≡ ua(e). Transport von f(𝟐) entlang p liefert e(f(𝟐)(u)) = f(𝟐)(u). Aber Π(x:𝟐) ¬(e(x) = x) — Widerspruch [[11]].
Corollary 3.2.7 [[11]]: Also auch nicht Π(A:𝒰) (A + ¬A).

Remark 3.2.5 [[11]]: „there can be no Hilbert-style 'choice operator' which selects an element of every nonempty type. The point is that no such operator can be natural, and under the univalence axiom, all functions acting on types must be natural with respect to equivalences."
Die Lösung: beschränke auf mere propositions (3.4.1 [[11]]):
LEM :≡ Π(A:𝒰) (isProp(A) → (A + ¬A))
Das ist konsistent. Der Unterschied: 𝟐 ist keine mere proposition, also betrifft LEM es nicht.
