📐 Formaler Rahmen – Schritt für Schritt

1. "Offene Menge" – was bedeutet das? Eine offene Menge ist eine Region, die ihren Rand nicht enthält. Auf dem Zahlenstrahl ℝ sind offene Intervalle (a,b) das einfachste Beispiel: jeder Punkt im Inneren hat links und rechts noch Platz, bevor die Grenze kommt. Offene Mengen sind die Grundbausteine der Topologie – sie sagen uns, was "lokal" oder "in der Nähe" bedeutet. Wenn wir von "lokalen Daten" sprechen, meinen wir: Daten auf einer offenen Menge.

2. Die Zuordnung: Region → Daten ℱ ordnet jeder offenen Menge U einen Datenwert ℱ(U) zu. Konkretes Beispiel: ℱ(U) = Menge aller stetigen Funktionen f: U → ℝ. Die Elemente von ℱ(U) heißen "Schnitte über U".

3. "Kontravariant" – die Pfeile drehen sich um Wenn V ⊆ U (V ist eine kleinere Region), können wir Daten von U auf V einschränken. Bei Funktionen: schränke den Definitionsbereich ein. Das ergibt eine Abbildung ℱ(U) → ℱ(V).
Inklusion V ↪ U → Restriktion ℱ(U) → ℱ(V) Die Pfeilrichtung kehrt sich um – genau das heißt "kontravariant". Ein "kovarianter" Funktor würde ℱ(V) → ℱ(U) liefern, aber das wäre hier sinnlos (woher sollen die Daten auf der größeren Menge kommen?).

4. "In eine Kategorie" – welche Struktur haben die Daten? Die Zielkategorie 𝒞 legt fest, welche Struktur ℱ(U) hat: Mengen (nur Ansammlung von Schnitten), abelsche Gruppen (man kann addieren), Vektorräume (man kann addieren und skalieren), Ringe (man kann multiplizieren). Für stetige Funktionen ℝ→ℝ sind die ℱ(U) reelle Vektorräume.

Zusammenfassung: Eine Prägarbe ist eine Vorschrift, die (a) jeder offenen Menge U ein Objekt ℱ(U) zuordnet, und (b) jeder Inklusion V ⊆ U eine Restriktionsabbildung ℱ(U) → ℱ(V) – in die Gegenrichtung. Das ist die Essenz von "kontravarianter Funktor von offenen Mengen in eine Kategorie".

KI-Anwendung

Lokale Konsistenz → Globale Kohärenz: In der KI-Forschung modellieren Garben:

  • Informationsfusion: Sensordaten verschiedener Quellen verkleben

  • Neuronale Netze: Lokale Repräsentationen auf Patches eines Bildes

🔗 Beziehungen der Konzepte

📦 Prägarben (Presheaves)

Definition

Prägarbe – die Datenstruktur

Konkret: Eine Prägarbe ℱ auf einem Raum X besteht aus:

  • Daten für jede offene Region: Für jede offene Menge U ⊆ X gibt es eine Menge (oder Gruppe, etc.) ℱ(U) – die "Schnitte über U". Beispiel: ℱ(U) = {stetige Funktionen f: U → ℝ}.
  • Einschränkung beim Verkleinern: Wenn V ⊆ U, gibt es eine Restriktionsabbildung ρVU: ℱ(U) → ℱ(V). Bei Funktionen: schränke den Definitionsbereich ein. Notiert oft als s ↦ s|V.
  • Verträglichkeit: Für W ⊆ V ⊆ U ist ρWU = ρWV ∘ ρVU – direkt von U nach W einschränken ist dasselbe wie über V.

Kategorientheoretisch (Formel oben): Eine Prägarbe ist ein kontravarianter Funktor. Die "Kategorie der offenen Mengen" hat die offenen Mengen als Objekte und die Inklusionen V ⊆ U als Pfeile. Der Funktor bildet jede offene Menge U auf ℱ(U) ab, und jeden Inklusionspfeil V → U auf die Restriktion ℱ(U) → ℱ(V) – in Pfeilrichtung umgekehrt ("kontravariant").

Wichtig: "Schnitte" heißen die Elemente von ℱ(U), weil man sie sich wie "Funktionsabschnitte" vorstellen kann – als ob man eine Funktion auf U aufschneidet und nur den Teil über V betrachtet.

Intuition

Denke an eine Prägarbe wie eine Datenbank:

  • Für jede "Region" (offene Menge) speicherst du Daten
  • Wenn du eine kleinere Region betrachtest, kannst du die Daten "einschränken"
  • Einschränkungen sind transitiv: erst von W auf V, dann von V auf U = direkt von W auf U

🌾 Garben (Sheaves)

Definition

Garbe

Eine Prägarbe ist eine Garbe, wenn für jede offene Überdeckung gilt:

(S1) Eindeutigkeit: Stimmen zwei Schnitte lokal überein, so sind sie gleich.

(S2) Existenz (Verkleben): Lokale Schnitte, die auf Überlappungen übereinstimmen, lassen sich zu einem globalen Schnitt zusammensetzen.

Intuition

Die Garben-Axiome in einem Satz:

"Lokale Daten bestimmen globale Daten eindeutig, sofern sie auf Überlappungen konsistent sind."

🌱 Halme (Stalks)

Definition

Halm einer (Prä)garbe

Der Halm ist der direkte Limes (gefilterter Kolimes) über alle offenen Umgebungen von .

Ein Element des Halms heißt Keim (germ): Es ist ein Paar , wobei zwei Paare äquivalent sind, wenn die Schnitte auf einer kleineren Umgebung übereinstimmen.

Intuition

Der Halm = "unendlich lokale" Information am Punkt x.

Denke an den Keim einer Funktion: Zwei Funktionen haben denselben Keim bei x, wenn sie in einer (beliebig kleinen) Umgebung von x übereinstimmen. Der Halm vergisst alles außer dem "infinitesimalen Verhalten" bei x.

Globaler Schnitt → Lokaler Schnitt → Keim (Halm)

Schlüsselsatz

Isomorphie auf Halmen ⟺ Isomorphie von Garben

KI-Anwendung

Halme = Lokale Repräsentationen

In der KI: Der Halm bei einem Datenpunkt x entspricht der lokalen Repräsentation – alle Information, die man aus beliebig kleinen Umgebungen von x extrahieren kann. Das ist verwandt mit:

  • Lokale Erklärbarkeit (LIME): Approximation eines Modells in der Umgebung eines Punktes
  • Tangentialraum in Manifold Learning: Lokale lineare Approximation
  • Attention-Mechanismen: Lokale Kontextfenster als "Umgebungen"

🔀 Morphismen & Funktorialität

Definition

Morphismus von (Prä)garben

Ein Morphismus ist eine natürliche Transformation: Für jede offene Menge U eine Abbildung , kompatibel mit Restriktionen.

Ein Morphismus von Garben ist wie eine "konsistente Transformation": Egal ob du erst einschränkst und dann transformierst, oder erst transformierst und dann einschränkst – das Ergebnis ist dasselbe.

🏗️ Konstruierbare Garben & Exodromie

Definition

Stratifizierung

Eine Stratifizierung eines Raumes X über einem Poset P ist eine stetige Abbildung (P mit Alexandroff-Topologie). Die Faser heißt Stratum.

Definition

Konstruierbare Garbe

Eine Garbe F auf X ist P-konstruierbar, wenn lokal konstant ist für alle p ∈ P.

Idee: Die Garbe darf "springen", aber nur an den Stratengrenzen. Innerhalb jedes Stratums ist sie brav (lokal konstant).

Beispiel

Konstruierbare Garben auf ℝ

Stratifizierung: ℝ → {0 → 1} mit X₀ = {0}, X₁ = ℝ \ {0}.

✓ Konstruierbar:

  • Konstante Garbe ℤ
  • Wolkenkratzer-Garbe ℤ₀
  • i*(ℤ ⊕ ℤ) auf {0}

✗ Nicht konstruierbar (bzgl. dieser Stratifizierung):

  • Garbe die auf ℝ\{0} nicht lokal konstant ist
Definition

Exit-Pfad-Kategorie

Die Exit-Pfad-Kategorie ExitP(X) hat:

  • Objekte: Punkte x ∈ X
  • Morphismen: Homotopieklassen von Exit-Pfaden – Pfade γ: [0,1] → X, bei denen f∘γ monoton steigend ist

Intuition: Du darfst dich nur "nach oben" durch die Strata bewegen – nie zurück in ein niedrigeres Stratum!

Intuition – Exit-Pfade

✓ Erlaubt: Von niedrigem Stratum zu höherem

✗ Verboten: Zurück in ein niedrigeres Stratum

Vergleich mit dem Fundamentalgruppoid:

  • Π₁(X) = Exit-Pfade wenn P = {*} (triviale Stratifizierung)
  • ExitP(X) ist eine "gerichtete" Version von Π₁(X)

🎮 Interaktiv: Exit-Pfade auf S¹

Stratifizierung: S¹ → {0 → 1 → 2} mit einem Punkt in Stratum 0, zwei Bögen in Stratum 1, und einem Punkt in Stratum 2.

Hauptsatz – Exodromie

Der Exodromie-Satz

Für eine konische Stratifizierung f: X → P gibt es eine Äquivalenz von Kategorien:

ConsP(X) ≃ Fun(ExitP(X), Set)

Eine konstruierbare Garbe F wird zum Funktor x ↦ Fx (Halme), und ein Exit-Pfad γ: x → y wird zur Abbildung Fx → Fy (Monodromie entlang γ).

Intuition – Exodromie vs. Monodromie

Monodromie (klassisch):

Lokal konstante Garben ↔ Darstellungen von π₁

Fun(Π₁(X), Set) ≃ Loc(X)

Exodromie (Verallgemeinerung):

Konstruierbare Garben ↔ Funktoren auf Exit-Pfaden

Fun(ExitP(X), Set) ≃ ConsP(X)

Die Exodromie verallgemeinert die Monodromie: Wenn P = {*}, dann ExitP(X) = Π₁(X) und ConsP(X) = Loc(X).

Beispiel

Exodromie für ℝ → {0 → 1}

Stratifizierung: X₀ = {0}, X₁ = ℝ \ {0}.

ExitP(ℝ) hat:

  • Objekte: alle Punkte von ℝ
  • Morphismen: Pfade die von X₁ nach X₀ gehen dürfen, aber nicht zurück

Ein Funktor darauf ist: eine Menge A (Halm bei 0), eine Menge B (Halm auf ℝ\{0}), und zwei Abbildungen B → A (von links und rechts).

KI-Anwendung

Exodromie & KI: Gerichtete Information

Die Exit-Pfad-Kategorie modelliert gerichteten Informationsfluss:

  • Hierarchische Modelle: Information fließt von feinen zu groben Schichten (wie in U-Nets, Feature Pyramids)
  • Stratifizierte Datenräume: Daten mit verschiedenen "Regimes" (z.B. Phase Transitions in physikalischen Systemen)
  • Kausalität: Exit-Pfade als kausale Pfade – Information fließt nur in eine Richtung
  • Attention in Transformers: Masked Attention = nur "Exit-Pfade" in der Zeitrichtung erlaubt
