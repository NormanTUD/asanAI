📐 Formaler Rahmen

Offene MengenRegionen ohne Rand; z.B. Intervalle (a,b) auf ℝ. Definiert, was "lokal" bedeutet. sind die Grundbausteine der Topologie. Eine PrägarbeOrdnet jeder offenen Menge U Daten ℱ(U) zu, z.B. stetige Funktionen auf U. ℱ ordnet jeder offenen Menge U Daten ℱ(U) zu (dem SchnittEin Element von ℱ(U); vorstellbar als Funktion oder Datensatz auf der Region U. über U) und jeder InklusionEinbettung V ⊆ U einer kleineren in eine größere Menge. V ⊆ U eine RestriktionsabbildungSchränkt Daten von der großen auf die kleine Menge ein. Bei Funktionen: Definitionsbereich verkleinern. ℱ(U) → ℱ(V).

Die Pfeilrichtung kehrt sich um (Inklusion V→U wird zu Restriktion ℱ(U)→ℱ(V)) – das heißt kontravariantEin Funktor, der Pfeile umdreht: aus V⊂U wird ℱ(U)→ℱ(V) statt ℱ(V)→ℱ(U).. Die Zielkategorie 𝒞Legt die Struktur der ℱ(U) fest: Mengen, abelsche Gruppen, Vektorräume, Ringe, ... bestimmt, ob ℱ(U) nur eine Menge oder mit Addition (Gruppe), Skalierung (Vektorraum) oder Multiplikation (Ring) ausgestattet ist.

KI-Anwendung

Lokale Konsistenz → Globale Kohärenz: Verteilte Modelle, Informationsfusion, TDA, CNNs.

🔗 Beziehungen der Konzepte

📦 Prägarben (Presheaves)

Definition

Prägarbe

ℱ ordnet jeder offenen Menge U Daten ℱ(U) zu (Schnitte, z.B. stetige Fkt.) und jeder Inklusion V ⊆ U eine Restriktion ℱ(U) → ℱ(V) (Einschränken). Transitiv: direkt von U→W = erst U→V dann V→W.

Intuition

Datenbank-Analogie: Region ↦ Daten. Kleinere Region ↦ eingeschränkte Daten. Transitiv wie `SELECT ... WHERE`.

Beispiel

Stetige Funktionen (Garbe ✓)

Restriktion = normale Funktionseinschränkung. Verkleben funktioniert → Garbe.

Beispiel

Beschränkte Funktionen (keine Garbe ✗)

Zwei beschränkte Fkt. auf überlappenden Intervallen können zusammen unbeschränkt sein → Verkleben scheitert.

🌾 Garben (Sheaves)

Definition

Garbe = Prägarbe + Verkleben

Eine Prägarbe ℱ ist eine Garbe, wenn für jede offene Überdeckung U = ⋃Uᵢ gilt:

(S1) Eindeutigkeit: Lokal gleiche Schnitte sind gleich.

(S2) Existenz: Auf Überlappungen passende Schnitte verkleben zu genau einem globalen Schnitt.

Intuition

"Lokale Daten ↦ globale Daten, wenn auf Überlappungen konsistent."

Konstante Prägarbe (✗) vs. Konstante Garbe (✓)

✗ ℱ(U)=G für alle U. Für disjunkte U,V verlangt Garbe G×G, Prägarbe gibt nur G.

✓ Lokal konstante Fkt. Verkleben funktioniert.

Wolkenkratzer-Garbe (Skyscraper)

Nur an Punkt x ≠ 0: ℱ(U)=G wenn x∈U, sonst 0. Wie Dirac-Delta.

🌱 Halme (Stalks)

Definition

Halm einer (Prä)garbe

Halm ℱx"Unendlich lokaler" Wert einer Garbe am Punkt x. Enthält alle Information aus beliebig kleinen Umgebungen von x. = direkter Limes über Umgebungen von x. Elemente heißen KeimeÄquivalenzklasse von Schnitten, die in einer kleinen Umgebung von x übereinstimmen.: (U,s) ∼ (V,t) wenn s und t auf einer kleineren Umgebung W ⊆ U∩V gleich sind.

Intuition

Halm = infinitesimale Info am Punkt x.
Zwei Funktionen haben denselben Keim bei x, wenn sie auf einer (beliebig kleinen) Umgebung übereinstimmen. Der Halm vergisst alles außer dem lokalen Verhalten bei x.

Global → Lokal → Keim (Halm)

✨ Garbifizierung (Sheafification)

Definition

Garbifizierung ℱ → ℱ⁺

Repariert eine Prägarbe zur nächstgelegenen Garbe: identifiziert lokal gleiche Schnitte (S1) und fügt fehlende Verklebungen hinzu (S2). Halme bleiben gleich.

Intuition

Zu viele Schnitte (S1 verletzt):
→ Identifiziere lokal gleiche

Zu wenige Schnitte (S2 verletzt):
→ Füge Verklebungen hinzu

Konstante Prägarbe → Konstante Garbe

ℱpre(U)=GKonstante Prägarbe: Jeder offenen Menge wird dieselbe Gruppe G zugeordnet. → ℱ⁺(U) = lokal konstante Fkt. U→G.

Beschränkte → alle stetigen Funktionen

Garbifizierung der beschränkten stetigen Fkt. = alle stetigen Fkt. (denn jede stetige Fkt. ist lokal beschränkt).

🎮 Interaktiv: Garbifizierung in Aktion

Halme bleiben erhalten

ℱx ≅ ℱ⁺x für alle x. Garbifizierung ändert Halme nicht.

🔀 Morphismen & Funktorialität

Definition

Morphismus von (Prä)garben

Eine Familie φU: ℱ(U) → 𝒢(U) für alle U, verträglich mit Restriktion: einschränken + transformieren = transformieren + einschränken.

Intuition

Konsistente Transformation: egal ob zuerst eingeschränkt oder zuerst transformiert – Ergebnis gleich.

Verdopplung φ(f)=2f

Auf der Garbe stetiger Fkt.: φ(f)=2f ist ein Garben-Isomorphismus.

Kern, Bild, Kokern

Kern (↦0) = Garbe. Bild = Prägarbe, muss garbifiziert werden. Kokern (B/Im) = Prägarbe, muss garbifiziert werden.

Surjektivität ist lokal!

φ surjektiv als Garbenmorphismus ⟺ surjektiv auf allen Halmen. Muss nicht für jedes U surjektiv sein!

exp: 𝒪 → 𝒪× auf ℂ*: lokal hat jede Fkt. einen Logarithmus (surjektiv), global nicht (kein globaler log der Identität).

Exakte Sequenzen

0 → ℱ → 𝒢 → ℋ → 0 ist exakt ⟺ für alle x: 0 → ℱx → 𝒢x → ℋx → 0 exakt.

💎 Garbenkohomologie

Definition

Garbenkohomologie Hⁱ(X, ℱ)

Hⁱ = i-ter rechtsabgeleiteter Funktor von Γ(X, –). Berechnung via injektiver Auflösung 0 → ℱ → I⁰ → I¹ → …

Intuition

"Kohomologie = Obstruktionen gegen lokales→globales Verkleben"

  • H⁰(X, F) = globale Schnitte
  • H¹(X, F) = Obstruktionen (z.B. kein globaler Logarithmus auf ℂ*)

H¹(ℂ*, ℤ) ≅ ℤ → es gibt keinen globalen Logarithmus!

Beispiel

Čech-Kohomologie

Über offene Überdeckung berechnet. Wenn alle Durchschnitte azyklischHöhere Kohomologie verschwindet, z.B. kontrahierbare Mengen. → isomorph zur Garbenkohomologie.

🏗️ Konstruierbare Garben & Exodromie

Definition

Stratifizierung

StratifizierungZerlegung eines Raumes in Schichten (Strata), z.B. ℝ = {0} ∪ ℝ\{0}. f: X → P zerlegt X in Schichten (Strata). Poset PHalbgeordnete Menge; definiert welche Strata aneinandergrenzen dürfen. gibt die Ordnung der Strata an.

Definition

Konstruierbare Garbe

Auf jedem Stratum lokal konstant. Darf nur an Stratum-Grenzen "springen".

Konstruierbare Garben auf ℝ (Stratifizierung: 0 vs. ℝ\{0})

✓ Konstruierbar: Konstante Garbe ℤ, Wolkenkratzer ℤ₀, i*(ℤ⊕ℤ)

✗ Nicht konstruierbar: Garbe, die auf ℝ\{0} nicht lokal konstant ist

Definition

Exit-Pfad-Kategorie

Objekte: Punkte x ∈ X. MorphismenHomotopieklassen von Pfaden γ: [0,1]→X mit monoton steigender Stratifizierung f∘γ.: Exit-Pfade (nur "aufwärts" durch Strata, nie zurück).

✓ Nur aufwärts (zu höherem Stratum)

✗ Nie zurück (zu niedrigerem)

🎮 Interaktiv: Exit-Pfade auf S¹

Stratifizierung: S¹ → {0 → 1 → 2} mit einem Punkt in Stratum 0, zwei Bögen in Stratum 1, und einem Punkt in Stratum 2.

Exodromie-Satz
ConsP(X) ≃ Fun(ExitP(X), Set)

Konstruierbare GarbenGarben die auf jedem Stratum lokal konstant sind und an Stratum-Grenzen springen dürfen. = Funktoren von der Exit-Pfad-Kategorie in Mengen. Halm bei x = Wert des Funktors auf x. Exit-Pfad γ: x→y = Abbildung Fx→Fy.

Monodromie (klassisch):
Loc(X) ≃ Fun(Π₁(X), Set)

Exodromie (allgemein):
ConsP(X) ≃ Fun(ExitP(X), Set)

Exodromie verallgemeinert MonodromieFür P={*} ist ExitP(X)=Π₁(X) und ConsP(X)=Loc(X)..

Exodromie für ℝ: {0} ∪ ℝ\{0}

Exit-Kategorie ≅ • ← • → •. Ein Funktor = Menge A (Halm bei 0) + Menge B (Halm auf ℝ\{0}) + zwei Abbildungen B → A.
