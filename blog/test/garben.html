🔑 Durchgängiges Beispiel: Basisraum X = ℝ (die Zahlengerade). Zu jeder offenen Menge U ⊂ ℝ ordnen wir die Menge der stetigen Funktionen zu: F(U) = C(U, ℝ). So wird jeder abstrakte Begriff sofort konkret vorstellbar.
Begriff Intuition Konkretes Beispiel Visualisierung Formalismus
Topologischer Raum (X, τ) Dein Wissensgebiet – das „Terrain“, auf dem alles lebt. Die reelle Zahlengerade ℝ mit den offenen Intervallen als Topologie.
Die Zahlengerade als Basis
 Paar (X, τ): Menge X mit Topologie τ (System offener Teilmengen).
Schnitt s ∈ F(U) Ein Datum, das über einem Gebiet U definiert ist. Auf U = (0, 2) ist s(x) = x² ein Schnitt – eine stetige Funktion nur über diesem Intervall.
Stetige Funktion nur über U
 Für U ∈ τ ist F(U) Menge/Gruppe/Modul. s ∈ F(U) = Γ(U, F).
Einschränkung ρU,V Das Beschränken eines Datums auf einen kleineren Bereich. Schränke s(x)=x² von U=(0,2) auf V=(0,1) ein: gleiche Formel, kleinerer Definitionsbereich.
Ausschneiden auf Teilbereich
 Morphismus ρU,V: F(U)→F(V) für V⊂U, mit ρU,U=id und ρV,W∘ρU,V=ρU,W.
Halm Stalk: Fx Alles, was am Punkt x „lokal“ passieren kann. Am Punkt x=0: alle stetigen Funktionen auf irgendeiner kleinen Umgebung von 0 – zusammengefasst.
Immer kleinere Umgebungen um x
 Direkter Limes: Fx := lim→ F(U) über alle offenen U ∋ x.
Keim Germ: [s]x Wie ein Datum am Punkt x „aussieht“ – Verhalten in beliebig kleiner Umgebung. Der Keim von s(x)=x² in x=0 = alle Funktionen, die nahe 0 mit x² übereinstimmen.
Zwei Funktionen mit gleichem Keim in x
 Äquivalenzklasse: (s,U)~(t,V) ⇔ ∃W⊂U∩V, x∈W: s|W=t|W.
Prägarbe Presheaf Daten pro Gebiet – aber ohne Garantie, dass sie zusammenpassen. Ordne jedem U irgendwelche Zahlen zu, ohne dass Einschränkung tatsächlich Verkleben erlaubt.
Lokale Daten passen nicht zusammen
 Kontravarianter Funktor F: O(X)op → Set.
Garbe Sheaf Prägarbe mit Verklebbarkeit: aus konsistenten lokalen Daten wird eindeutig ein globales. Zwei stetige Funktionen auf U₁, U₂, die im Überlapp gleich sind, ergeben genau eine stetige Funktion auf U₁∪U₂.
Konsistente lokale Daten = ein globales
 Prägarbe F mit Equalizer für jede Überdeckung U=⋃Ui: F(U)→∏F(Ui)⇉∏F(Ui∩Uj)

Die 2 Grundaxiome mit Bildern

① Lokal–Global-Identität (Separatedness / Unizität)
Stimmen zwei globale Schnitte s, t ∈ F(U) auf jedem Teil Ui überein, so sind sie überall gleich:
(∀ i: s|Ui = t|Ui) ⇒ s = t
Zwei Schnitte, die lokal überall gleich sind, sind ein einziger Schnitt.
② Verklebbarkeit (Gluing / Existenz)
Lokale Schnitte si ∈ F(Ui), die auf allen Überlappungen zusammenpassen, lassen sich zu genau einem globalen Schnitt s ∈ F(U) verkleben:
si|Ui∩Uj = sj|Ui∩Uj ⇒ ∃! s ∈ F(U)
Drei lokal passende Stücke verkleben eindeutig zu einer Funktion.
Kompakt: Die beiden Axiome ⇔ Ein einziges Equalizer-Diagramm
F(U)  ⟶  ∏i F(Ui)  ⇉  ∏i,j F(Ui ∩ Uj)
Der linke Pfeil ist injektiv (= Axiom ①) und sein Bild ist genau der Equalizer der beiden rechten Pfeile (= Axiom ②).
