# TOKEN / EGO — technical notes

## 1. What kind of model is it?

A decoder-only transformer with pre-LayerNorm:

```
x_i^0 = E[token_i] + P_i
for l = 0 … L-1:
    a_i = LN(x_i^l)
    q_i = W_Q a_i,  k_i = W_K a_i,  v_i = W_V a_i
    s_ij = (q_i · k_j) / sqrt(d_head)      for j ≤ i
    α_ij = softmax_j(s_ij)
    z_i = Σ_j α_ij v_j
    x_i ← x_i + W_O z_i + b_O
    m_i = LN(x_i)
    h_i = GELU(W_1 m_i + b_1)
    x_i ← x_i + W_2 h_i + b_2
ln_f = LN(x)
logits = E · ln_f · scale + b_u
p = softmax(logits / T)
```

The implementation is in `src/model.js`. The forward pass stores a full trace: every `x_in`, `ln1`, `q`, `k`, `v`, score matrix, attention matrix, `z`, per-head output, `x_mid`, `ln2`, pre-activation, GELU, `ffn_out`, `x_out`, final vector, logits, probabilities, and the residual ledger.

The model is a hybrid of the original Transformer (sinusoidal positions) and GPT-2 (pre-LN, GELU, tied unembedding). It is not a GPT-2 checkpoint.

## 3. The weights are synthetic, the arithmetic is not

`buildWeights(seed)` in `src/model.js`:

- One orthogonal 32 × 32 rotation per head per projection (Q, K, V, O), generated by Gram-Schmidt on Gaussian vectors.
- W_Q/W_K/W_V/W_O are block-structured: head `h` writes/reads its own 32-dimensional slice, with a small amount of cross-slice leakage. This makes each head's computation visible without claiming that trained heads have fixed semantic roles.
- W₁: the first 128 neurons are near dimension detectors (one coordinate plus noise); the remaining 384 are random feature directions. W₂ is a random mixing back to 128 dimensions.
- LayerNorm γ ≈ 1, β ≈ 0 (small random perturbation).
- The unembedding is `E` with a logit scale of 0.9.

The token directions `E` are **not** synthetic: they are a PCA projection of real static embeddings from `model2vec potion-base-8M` (packed 4-bit). The generator is `tools/gen_embeddings.py`; it reads the vendored model, extracts 256-dimensional word vectors, centres them, takes the leading 128 principal components, and scales the average norm to 1.5. The 3D map used in the embedding space is the leading 3 components, rotated by a fixed rotation.

This is why the model's next-token distribution is a semantic association cloud rather than a trained continuation. The codex and the logits panel say so.

## 4. The residual stream is the spine

Every layer reads the residual stream through LayerNorm and writes back by addition. The trace includes the exact ledger:

```
x_final = x_0
        + Σ_l Σ_h head_write(l,h)
        + Σ_l attention_bias(l)
        + Σ_l ffn_write(l)
```

`trace.ledger` stores each term as a 128-dimensional vector. `trace.ledgerError` is the maximum absolute difference between the sum and `x_final`; it is printed in the residual panel. In a normal run it is below `1e-6`.

The visual contract:

- 128 bars around the central pillar = the player token's residual vector at the current phase.
- The bars morph between `x_in`, `x_mid` (after attention), and `x_out` (after FFN).
- The vertical collar + player trail + norm sparkline show the stream growing across layers.
- The six helices around the pillar are the braid of writes.

## 5. Attention internals

For the player token `i` and head `h`:

```
s_ij = (q_i^h · k_j^h) / sqrt(32)
s_ij = -∞                       if j > i
α_ij = exp(s_ij - max) / Σ_k exp(s_ik - max)
z_i^h = Σ_j α_ij v_j^h
```

The game shows:

- the raw score matrix `QKᵀ/√d`,
- the causal mask,
- the softmax matrix `α`,
- the player row in exact numbers,
- the value norms and weighted contributions `‖α·v‖`,
- the head-to-tail 2D projection of `Σ α v`,
- all four heads simultaneously in the 4-panel grid,
- all four heads' beams in the 3D scene (the selected head is bright, the others remain visible),
- the causal curtain for the future.

The numeric check in the panel reports `Σ α` and `max future α` (expected 1 and 0).

The Q/K/V ghost crystals show the token splitting into the three projections. The value particles flow from each attended token into the player. The player crystal's tint is a metaphor for the mixture; the exact values are in the budget list and the panel.

## 6. FFN internals

```
h_pre = W_1 · LN(x) + b_1       (512 values)
h     = GELU(h_pre)
y     = W_2 · h + b_2           (128 values)
x     ← x + y
```

The chamber shows:

- the 128 input values on the input ring,
- the 512 neurons in a Fibonacci sphere, coloured by GELU activation,
- the strongest W₁/W₂ connections of the top 12 neurons,
- the actual W₁ and W₂ matrices as holographic heatmaps,
- the GELU curve with all 512 (pre, post) points,
- a first-person camera path through the chamber: input → hidden sphere → output,
- the top active neurons and their share in the HUD,
- the flow canvas and the single-neuron detail in the math monitor.

The single-neuron panel shows the actual W₁ row and W₂ column. That is the concrete computation `GELU(w₁ · x + b) × W₂[:,n]`.

## 7. Embedding space: directions, not distances

A token embedding is a vector `E_i ∈ R^128`. Semantic similarity is

```
cos θ(E_i, E_j) = (E_i · E_j) / (‖E_i‖ ‖E_j‖)
```

A small angle means a similar direction. Euclidean distance is not the right metric; two long vectors can point in the same direction and be far apart in Euclidean terms. The game says this explicitly and shows `cos θ` in the neighbour list.

The 3D cloud is a PCA projection of the 128-dimensional directions. It is a map, not the full geometry. The player is placed at the origin of the recentred map; the 128 filaments are the dimensions of the player's vector (length = magnitude, colour = sign); the neighbour spokes and constellation lines show the nearest directions; the list gives the exact cosine. The direction sphere in the background is a reference, not a metric claim.

The position stage adds `P_pos` dimension by dimension: `x_0[d] = E[d] + P[d]`. The cyan/gold/white filaments and the HUD norms show the sum. The 3D cloud position is semantic, not the sequence position.

## 9. Rendering and audio

- Three.js r160 (vendored), `EffectComposer`, `UnrealBloomPass`, and a custom post pass (vignette, chromatic aberration, grain, scanline, colour grade).
- Custom shaders for the nebula, stars, crystals, beams, pillar, rings, lens, curtain, and neurons.
- All textures are generated on a canvas at runtime. No external assets, no CDN, no network.
- The audio is a small Web Audio score: drones, pads, pings, whooshes, chords, and a generated reverb impulse. It starts only after a user gesture.

## 10. Tests and checks

`tests/model_test.js` runs 21,693 assertions:

- shapes and trace completeness,
- ledger sum equals the final residual,
- attention rows sum to 1,
- future attention is exactly 0,
- entropy bounds,
- LayerNorm output mean ≈ 0 and variance ≈ 1,
- residual add identities `x_mid = x + attn` and `x_out = x_mid + ffn`,
- GELU reference values,
- determinism and seed sensitivity,
- single-token edge case,
- unknown-token failure,
- no NaNs or infinities,
- forward-pass timing.

The in-game attention panel independently reports `Σ α` and `max future α`; the residual panel reports the ledger reconstruction error. The panel tour (`?panel=1`) renders every math/weights/dims/codex/help/inspect view; the final test (`?finaltest=1`) runs the choose → continue loop. Both pass in headless Chromium.
