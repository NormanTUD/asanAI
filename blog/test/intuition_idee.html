👁️ Attention Heads als "Augen"

Jeder Head ist ein Auge, das auf einen anderen Aspekt der Beziehungen zwischen Tokens achtet.
So liest man die Matrix: Zeilen = Query-Tokens ("Ich schaue von hier aus"), Spalten = Key-Tokens ("Ich schaue dorthin hin"). Jede Zelle enthält den Attention-Score, den der ausgewählte Head diesem Paar zuweist. Das obere rechte Dreieck ist durch die Causal Mask auf 0 gesetzt — ein Token kann nur auf sich selbst und frühere Tokens schauen.
