Types as Spaces: The Circle and Univalence

Kernthese der Fusion

Both papers are visual introductions to the same theory — Homotopy Type Theory — and they make the identical foundational move: a type is not a bag of elements but a space. A term x : A is a point; a proof that a = b is not a true/false judgment but a path from a to b; a path between two paths (a homotopy) is an equality between equalities; and so on, forever. This is what makes every type an ∞-groupoid — equality is not just true, it has structure.

The single object that fuses the two together is the circle S¹. Paper A meets it as the higher-inductive type "one base point + one loop generator", from which it reads off π₁(S¹) ≁ ℤ (the winding number, via encode/decode transport). Paper B meets it as the continuous topological circle — a ring of points with a base point and a loop. The fused position is that these are the same type: the HIT circle is provably equivalent to the topological circle, and the Univalence Axiom — (A = B) ≁ (A ≁ B) — upgrades that equivalence to literal equality. The winding number is the bridge: at once the HIT's loop-space content and the topological fundamental group.

In one line: HoTT is a single language in which topology, logic, and type theory are the same subject; A supplies the formal algebraic backbone (groupoid operations, transport, the homotopy-level ladder), B supplies the spatial intuition and the "why it matters" unification. Shapes first, notation to name what the shapes are.

Widersprüche zwischen A und B

The two sources never contradict on a theorem — both correctly present HoTT. The tensions are in which picture of the same objects they commit to. Three specific, real ones:

  • 1 · What the circle S¹ "is". A ("The Circle S¹ and Its Loops") defines it inductively: "The circle has one point base and one non-trivial loop loop : base = base" — a single point plus a single loop generator, and it computes π₁(S¹) ≁ ℤ from that logical data. B ("Types as Spaces" → Circle S¹) draws it as a continuous geometric ring — ~100 plotted points, "a continuum of inhabitants", with a base point and a loop among them. The tension: A's S¹ is a discrete logical object (exactly one point + one loop); B's S¹ is a geometric continuum (infinitely many points). Incompatible pictures of the same symbol.
  • 2 · How Univalence is grounded. A (Univalence) grounds the axiom on discrete finite sets: "In set theory, {0,1} and {true,false} are different sets that happen to be isomorphic. Univalence says: if they're equivalent, treat them as literally equal." B (The Univalence Axiom) grounds it on continuous topological shapes: "A triangle and a circle are topologically equivalent (homeomorphic). Univalence says we can treat them as literally the same type." The tension: A instantiates (A ≁ B) ≁ (A = B) on finite/combinatorial sets; B on continuous/homeomorphic shapes. A discrete vs. a continuous reading of one principle.
  • 3 · Register: formulas vs. "no formulas". A is notation- and algebra-heavy: it develops the path groupoid (refl, p⁻¹, p · q), stresses that composition is associative only up to a 2-path α, develops transport p_* : P(x) → P(y) / fibrations, and the homotopy-level ladder (−2 … 2). B is explicit about its opposite stance — tagline "no formulas, just shapes and intuition" — and stays at pure spatial intuition (morphing curves, a 3D sphere for the higher-path tower, a Rosetta-Stone network); it does not develop the groupoid axioms, transport, or the level ladder. The tension: A's formal / weak-∞-groupoid register vs. B's intuition-only, anti-formula register.

Auflösung

Three resolutions, one per tension; together they yield the fused conclusion.

Auflösung 1 — the HIT circle is the topological circle

The HIT definition (1 point + 1 loop) is not a different object from the geometric ring — it is equivalent to it, and Univalence turns that equivalence into equality. Both pictures carry the same loop space ℤ: the winding number on A's HIT is exactly the fundamental group of B's topological circle.

Fused: present S¹ first as the HIT (its clean logical definition), then immediately note S¹(HIT) ≁ S¹(topological). "One point" (A) is a choice of presentation; the "continuum of points" (B) is its geometric model. HoTT is precisely what lets you move between them — the integer n is the invariant they share.

Auflösung 2 — one axiom, two registers

The discrete example (A) makes "bijection + coherence" visible — an equivalence is a two-way map that inverts up to the higher structure. The continuous example (B) makes "deformable / homotopic" visible — you can literally morph one shape into the other. These are the same content (A ≁ B) ≁ (A = B) seen from the set-theoretic and the topological side.

Fused: state the principle once, then illustrate with both a discrete instance ({0,1} ≁ {true,false}) and a continuous one (triangle ≁ circle). Discrete and continuous are complementary windows onto one axiom, not competing claims.

Auflösung 3 — intuition motivates, formalism justifies

The two registers are complementary, not contradictory. B's "shapes and intuition" is the entry point for the reader; A's groupoid operations, up-to-homotopy associativity, transport, and level ladder are the names for what the shapes are. B shows that equality "has structure"; A writes down the algebra of that structure.

Fused (with an honesty note): use B's spatial pictures to motivate, then A's notation to capture each idea. Both sources are expository visual guides rather than formal papers, so these "contradictions" are of emphasis and presentation — the fusion keeps the intuition as the surface and the formalism as the backbone.

Fusionierter Inhalt

1 · Types are spaces; terms are points

Both papers start here. A type A is a space; a term x : A is a point. The discrete anchors both agree on: Bool = {true, false} (2 isolated points, no path between them); ℕ (B) as a countably infinite discrete line of points; the empty type ∅ (B) — the void, logic's False, a proposition with no proof; and the contractible / Unit type (A) — exactly one point up to homotopy.

2 · Equality is a path (proof-relevance)

For x, y : A, the identity type x = y is the space of paths from x to y. A proof that x = y is a specific path; distinct proofs are distinct paths — this is proof-relevant mathematics, where the space of equalities can itself be rich. refl_x : x = x is the constant path. B makes it visual (morphing curves, each a different proof of the same equality); A names it and shows the continuous deformation.

3 · Path operations — the weak ∞-groupoid (A's strength)

Paths carry three operations:

  • Reflexivity — refl_x : x = x, the constant path (identity).
  • Inverse — p : x = y gives p⁻¹ : y = x (symmetry).
  • Composition — p : x = y, q : y = z give p · q : x = z (transitivity).

The decisive subtlety A stresses: composition is associative only up to a higher path — (p · q) · r and p · (q · r) are not literally equal but are joined by a 2-path α. This "weakness up to higher paths" is exactly what makes types ∞-groupoids, not ordinary groups.

refl : x = x (identity path) p⁻¹ : y = x (inverse of p : x = y) p · q : x = z (composition) α : (p · q) · r = p · (q · r) (associativity, only up to a 2-path)

4 · Higher paths = homotopies; the tower to ∞

A path p = q between two paths is a 2-path / homotopy — a continuous deformation from one path to the other (A's filled green region; B's translucent surface/2-cell on a sphere). B makes the infinite tower explicit: points → paths → homotopies → homotopies of homotopies → … Each level is "the paths between" the previous one.

Every n-type is also an (n+1)-type; the ladder climbs to ∞. B's 0/1/2 levels on a sphere are the geometric shadow of this ladder.

6 · Transport along paths (fibrations) (A's strength)

Given a family P : A → Type and a path p : x = y, transport gives a function between the fibers, p_* : P(x) → P(y): carry an element of the fiber over x along p to an element over y. This makes type families into fibrations. It is the mechanism behind A's proof of π₁(S¹) ≁ ℤ: transport around the loop and apply successor / predecessor to 0 (the encode/decode construction).

7 · The circle S¹ — the fused object

A (HIT): one point base + one loop loop : base = base; its loop space is ℤ, so π₁(S¹) ≁ ℤ; the integer is the winding number. B (topological): a continuous ring of points with a base point and a loop; "the space of loops here is equivalent to the integers ℤ (winding numbers)". Fused: same type. The HIT is a definition (1 point + 1 loop) provably equivalent to the topological circle; Univalence makes them equal. The winding number is simultaneously the HIT's loop-space content and the topological fundamental group.

S¹ (HIT) : base : S¹, loop : base = base (1 point + 1 loop) S¹ (topo) : continuous ring, base : S¹, loop a path base → base S¹(HIT) ≁ S¹(topo) (equivalent; hence equal, by Univalence) π₁(S¹) ≁ ℤ (winding number n ∈ ℤ)

8 · Univalence

The Univalence Axiom: (A = B) ≁ (A ≁ B) — the type of equivalences between two types is itself the type of equalities. A's discrete instance: {0,1} ≁ {true,false} — "different" sets in set theory, but equivalent, hence equal in HoTT, so every theorem about one transfers to the other for free. B's continuous instance: triangle ≁ circle (homeomorphic) — deformable, hence equal. Consequence (both): structure-preserving equivalence is identity; isomorphic structures share all properties.

9 · Why it matters — the Rosetta Stone (B's strength)

B's unifying map: one language in which three fields are the same subject read in three dialects —
