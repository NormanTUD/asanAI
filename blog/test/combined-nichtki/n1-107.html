HoTT: das Formalbeweis-System und der Konstruktionsmotor

Kernthese der Fusion

Beide Papiere gründen auf derselben Interpretation: Typen sind Räume, Terme sind Punkte, ein Gleichheitsbeweis p : a = b ist ein Pfad, und ein Beweis, dass zwei Pfade gleich sind (eine Homotopie), ist ein Pfad zwischen Pfaden. So entsteht auf jeder Stufe ein ∞-Gruppoid. Davon ausgehen, ist die Fusion nicht „zwei Texte über dasselbe“, sondern ein Objekt in drei Lesarten: Raum (Topologie/Geometrie), Beweis-Sprache (Logik/Informatik) und Bausatz (Analysis).

Die beiden Quellen lesen diesen einen Apparat aber unterschiedlich. A · hott5 liest ihn als Formal- und Beweissystem zu beherrschen: Typen & Terme, Pfade & Gleichheit, Homotopien, Trunkierungs-Level (h-Level), das Univalenz-Axiom, höhere induktive Typen, ein schrittweise nachvollziehbarer Beweis von π₁(S¹) ≅ ℤ, dazu Term-Spielplatz und Quiz. B · hott_practical liest denselben Apparat als Konstruktions-Engine: man baut daraus den Zahlenturm 0,1,2 → N → ℤ → ℚ → ℝ, definiert Arithmetik durch Rekursion/Induktion, und jede Operation muss die Äquivalenzrelation ihres Quotienten bzw. seiner Vervollständigung respektieren.

Die fusionierte Position: Mathematik ist ein kohärentes Objekt, das zugleich Raum, Beweis-Sprache und Bausatz ist — und das Univalenz-Axiom ist der Klebstoff, der „gleich bis auf Äquivalenz“ zu buchstäblicher Gleichheit macht. Emblematisch ist der Kreis: Dass π₁(S¹) ≅ ℤ in A ein Beweis und in B eine Konstruktion (Zahlen als Windungszahlen, ℤ ≃ Ω(S¹)) ist, ist dasselbe Ergebnis — und in konstruktiver Mathematik sind Beweis, Algorithmus und geometrisches Objekt einerlei.

Widersprüche zwischen A und B

Im Kern widersprechen sich die beiden Papiere nicht: Typen = Räume, Terme = Punkte, Gleichheit = Pfade, Homotopien = 2-Pfade, Univalenz und der Kreissatz π₁(S¹) ≅ ℤ — all das stimmen sie. Die realen Spannungen sind komplementäre Emphases; hier die konkretesten, wörtlich benannt:

1. Zweck & Fokus

A zielt darauf, den Formalismus zu beherrschen („Lerne den Formalismus von HoTT und berechne echte mathematische Ergebnisse“); der Sektionsrücken ist Typen & Terme → Pfade → Homotopien → h-Level → Univalenz → Spielplatz → Quiz. B zielt darauf, die Mathematik zu bauen („…constructs numbers from fundamental types, defines arithmetic operations…“); der Rücken ist Foundations → Naturals → Integers → Rationals → Reals → Arithmetic → Geometry → Live-Calculator. A fragt „was ist ein korrekter Beweis?“, B fragt „wie baue ich Analysis aus nichts?“. Gleiche Maschine, unterschiedliche Fragestellung.

2. Der Kreissatz — dasselbe Ergebnis, entgegengesetzte Haltung

A macht aus π₁(S¹) ≅ ℤ den Beweis-Höhepunkt: eine universelle Überdeckung cover mit cover(base) ≡ ℤ und ap(cover, loop) = ua(succ-equiv), dann encode(p) = transport(cover, p, 0) und decode(n) = loopⁿ, und es werden encode∘decode = id sowie decode∘encode = id gezeigt. B macht daraus eine operationelle Pflicht: Division ist nur mit einem expliziten Zeugen für b ≠ 0 definiert — ein Term vom Typ (b = 0) → Empty; bei den Realen unterscheidet es sogar „apart from 0 (constructive non-zero)“ von bloßer Ungleichheit; bei ℚ/ℤ muss man beweisen, dass add/mul/div die Äquivalenzrelation respektieren. B führt mit dem emphatischen Satz ein: „equality is not a proposition but a type that can have multiple inhabitants.“

Auflösung

(1) Grammatik vs. Programm. A ist die Beweis-Theorie, B das Programmieren in ihr. Man braucht beide: A’s h-Level klassifizieren genau die Typen, die B baut (Nat/Bool = h-Level 0, Ω(S¹) = h-Level 1, S² = h-Level 2), und B’s Turm liefert A konkrete Typen auf jeder Stufe. Fusion: Ein Formalismus ohne Konstruktion bleibt abstrakt, eine Konstruktion ohne Formalismus nicht verifizierbar.

(2) Beweis = Konstruktion. Der Kreissatz ist beides zugleich: als Beweis (A) zeigt er, dass der Apparat Zähne hat; als Konstruktion (B) zeigt er, dass er echte Struktur erzeugt. Entscheidend: encode/decode sind selbst die geometrischen Windungsabbildungen — der formale Beweis trägt die Konstruktion als Inhalt. Fusion: „Beweis = Algorithmus = geometrisches Objekt.“

(3) Der Zeugen-Druck ist ein Feature, kein Bug. B’s „Operationen brauchen Zeugen“ ist exakt A’s „jeder Beweis ist ein Algorithmus“, angewandt: der Wohldefiniertheits-Beweis ist der Algorithmus, der Nicht-Null prüft. Und Univalenz + Transport (aus A) machen B’s „Arithmetic Transfer“ möglich — Operationen werden einmal definiert und entlang ua(e) in jede äquivalente Darstellung verschoben: add_2 = transport(ua(e), add_1).

(4) Trunkierung erklärt das Phänomen. A’s h-Level-Hierarchie ist die Erklärung für B’s „mehrere Pfade“: auf h-Level 0 (Mengen wie Nat/Bool) ist Gleichheit eine Proposition, auf höheren Leveln (Ω(S¹), der Pfadraum des Kreises) nicht. Fusion: A’s Klassifikator erklärt B’s höhere Pfadstruktur — Teil- und Ganzes statt Widerspruch.

Fusionierter Inhalt

1. Die einheitliche Interpretation

Die gemeinsame Grundtabelle — ein ∞-Gruppoid, in dem auf jeder Stufe Pfade vorkommen:

Typ A → Raum Term a : A → Punkt p : Id_A(a, b) → Pfad a → b (Gleichheitsbeweis) α : p =_{a=b} q → Homotopie (Pfad zwischen Pfaden) ∞-Gruppoid: → Pfade, 2-Pfade, 3-Pfade, … auf jeder Stufe

Pfad-Algebra AB: refl (reflexiv), p⁻¹ = inv(p) (symmetrisch), p · q = trans(p,q) (transitiv). Die Gruppoide-Gesetze — Einheiten, Inverse, Assoziativität — gelten nur bis auf Homotopie, nicht streng: refl · p = p, p⁻¹ · p = refl, (p·q)·r = p·(q·r) jeweils up-to-path. B betont, dass z. B. Kommutativität a+b = b+a ein Pfad ist — ein manipulierbares Beweis-Objekt, das durch Induktion konstruiert wird.

2. Der Grundtyp-Turm, gestuft nach h-Level

Der Turm B, mit A’s Trunkierungs-Klassifikation A verknüpft:

  • 0 (Empty) — kein Punkt — h-Level −2 (kontrahierbar); 1 (Unit, tt) — h-Level −2.
  • 2 (Bool, true/false) — h-Level 0 (Menge): Gleichheit ist Proposition.
  • N — Erzeuger 0, S : N → N + Rekursionsprinzip; add m 0 = m, add m (S n) = S(add m n); h-Level 0.
  • ℤ — drei äquivalente Konstruktionsarten: Coproduct N + 1 + N, Quotient (N×N)/~ mit (a,b)~(c,d) ⟺ a+d = b+c, und als Loop Space ℤ ≃ Ω(S¹). ℤ als Menge h-Level 0; Ω(S¹) selbst h-Level 1.
  • ℚ — Set-Quotient (ℤ × ℤ⁺)/~ mit (a,b)~(c,d) ⟺ a·d = c·b; Wohldefiniertheit der Operationen muss bewiesen werden.
  • ℝ — Cauchy-Reale (Cauchy-Folgen), Dedekind-Reale (Schnitte), oder HIT-Vervollständigung; der „Tower of Construction“.

3. Abhängige Typen & Transport

Abhängige Produkt-/Summentypen Π(x:A). B(x) / Σ(x:A). B(x) sind Faserungen — über jedem Basispunkt x liegt ein Raum B(x). Transport (beide): transport : (p : a =_A b) → B(a) → B(b) „schiebt“ ein Element x : B(a) entlang des Basis-Pfades p in die Faser über b. A zeigt es an der Faserung; B nutzt es für die Überdeckung des Kreises und für den „Arithmetic Transfer“.

4. Pfadinduktion (J-Eliminator)

Derselbe Mechanismus in beiden Papiern — A nutzt ihn, um plus-zero-right : Π(n:N). n + 0 = n durch Pfad-Induktion zu beweisen (Basisfall refl, Induktionsschritt ap(succ, IH)); B schreibt ihn als J-Eliminator nieder: J : (A : Type) → (C : (x y : A) → x = y → Type) → ((x : A) → C x x refl) → (x y : A) → (p : x = y) → C x y p Er ist der Grund, aus dem alle arithmetischen Gleichheits-Beweise (Right-Zero, Kommutativität, Assoziativität) erwachsen.

5. Univalenz — der Klebstoff

A definiert das Axiom und seine Konsequenzen; B wendet es auf Arithmetik an.

ua : (A ≃ B) → (A =_U B) isEquiv(ua) ⟹ (A ≃ B) ≃ (A =_U B)

Konsequenzen (A): isomorphe Gruppen sind gleich, äquivalente Kategorien sind gleich, homöomorphe Räume sind gleich — das Struktur-Invarianz-Prinzip: was in HoTT formulierbar ist, respektiert automatisch Äquivalenzen. Berechnung (A): Transport entlang ua(e) ist e: transport(λX. X, ua(not-equiv), true) ≡ not(true) ≡ false. Anwendung (B): „Arithmetic Transfer“ — weil die Darstellungen von ℤ äquivalent (also via Univalenz gleich) sind, wandert add zwischen ihnen ohne neuen Beweis.

6. Der Kreis S¹ (HIT) & der Brückensatz

Der Kreis ist ein höherer induktiver Typ — ein Punkt- und ein Pfad-Erzeuger:

data S¹ : Type where base : S¹ loop : base =_{S¹} base

Und der Brückensatz, der beide Papiere verbindet: π₁(S¹) ≅ ℤ bzw. ℤ ≃ Ω(S¹). A beweist ihn (Überdeckung + encode/decode); B liest ihn als Geometrie (Windungszahl = Zahl). Konsequenzen, die Arithmetik zu Pfad-Algebra machen: loop^m · loop^n = loop^(m+n) (Addition = Komposition), loop^0 = refl (Null = konstanter Pfad), negative Zahlen = umgekehrte Windung. Trunkierung: S¹ ist 1-Typ (Pfade zwischen Schleifen eindeutig, π₂(S¹)=0); S² ist 2-Typ (π₂(S²)≅ℤ).

7. Arithmetik durch Rekursion & der konstruktive Preis

add/mul entstehen durch Rekursion über S; B betont: „the path from the input to the output is the computation itself, witnessed by definitional equalities (refl)“. m + 0 = m ist definitorisch (refl); 0 + n = n und a + b = b + a sind dagegen echte Beweise. Der konstruktive Preis B: Division div braucht einen Zeugen b ≠ 0 : (b = 0) → Empty; bei ℝ verlangt es Apartness (konstruktives Nicht-Null), nicht bloße Ungleichheit. A’s Spielplatz-Evaluator wertet dagegen succ, n + m, not, refl, transport aus — derselbe Apparat, unterschiedlicher Fokus (Beweis-Typkorrektur vs. Reduktionsschritte).
