Code-Patterns aus dem Buch

Die Snippets aus dem Dokument — plus die Engineering-Prinzipien, die dahinterstehen.

tools/schemas.py · Typed Tool Input 
from pydantic import BaseModel, Field

class WeatherArgs(BaseModel):
    city: str = Field(..., min_length=2)
    units: str = Field("metric",
        pattern="^(metric|imperial)$")

Typed Schemas reduzieren halluzinierte Parameter und liefern klare Fehler, die du zum Agenten zurückrouten kannst — Self-Repair [[11]].

tools/web_search.py · Custom Tool Wrapper 
import httpx
from pydantic import BaseModel

class SearchArgs(BaseModel):
    q: str
    k: int = 5

async def web_search(args: SearchArgs) -> dict:
    async with httpx.AsyncClient(timeout=10.0) as client:
        r = await client.get(
            "https://example.com/search",
            params=args.model_dump())
        r.raise_for_status()
        return r.json()

Deterministisch, validiert, timeout-safe. Auch wenn dein Framework Decorators hat — die Engineering-Prinzipien bleiben dieselben [[11]].

tools/errors.py · Recoverable Errors 
# Strukturierte Fehler → Agent kann sich selbst reparieren
class ToolError(BaseModel):
    code: str          # TIMEOUT | VALIDATION | AUTH
    message: str
    retryable: bool   # steuert Backoff vs. Repair

# retryable  -> exponential backoff (gecappt!)
# !retryable -> Modell repariert Argumente
# immer: Fehler in Logs/Traces exponieren
