Garbentheorie

Was ist eine Garbe?

Ein Rezept, das jedem Stück Raum die Daten zuordnet, die dort lokal leben — und sagt, wie man sie verklebt.

↓ Scrollen oder Pfeiltasten

01 · Prägarbe

Offene Mengen → Daten

Jede offene Menge U bekommt eine Menge von Schnitten ℱ(U). Wird U kleiner, kann man einschränken.

ρ : ℱ(U) ⟶ ℱ(V),  V ⊆ U
02 · Schnitte

Ein Schnitt ist ein Lift

Über jedem Punkt liegt eine Faser. Ein Schnitt wählt stetig aus jeder Faser einen Punkt — ein Graph über der Basis.

s : U ⟶ E,  π ∘ s = id
03 · Restriktion

Zoom nach innen

Einschränken verliert Information — nie umgekehrt. Immer kleinere Umgebungen um einen Punkt.

s|V ∈ ℱ(V)
04 · Keim

Der Keim im Punkt

Zwei Schnitte sind äquivalent in p, wenn sie auf irgendeiner Umgebung übereinstimmen. Die Klasse ist der Keim — der Limes allen Zoomens.

ℱp = colimp ∈ U ℱ(U)
05 · Halm

Alle Keime = Halm

Sammle alle Keime über p: das ist der Halm ℱp. Die Garbe wächst wie ein Feld — über jedem Punkt ein Halm.

ℱ = ⨆p∈X ℱp
06 · Axiome

Verkleben & Eindeutigkeit

Stimmen lokale Schnitte auf den Überlappungen überein, so verkleben sie zu genau einem globalen Schnitt. Das macht die Prägarbe zur Garbe.

si|Uij = sj|Uij ⟹ ∃! s
07 · Obstruktion

Lokal ja, global nein

Manchmal passt alles lokal — und trotzdem gibt es keinen globalen Schnitt. Die Monodromie dreht den Streifen. Das misst Kohomologie.

H¹(X, ℱ) ≠ 0
08 · Étalé-Raum

Die Garbe als Raum

Alle Halme nebeneinandergelegt ergeben einen Raum über X. Schnitte werden zu echten Blättern — sie überlagern die Basis.

π : Ét(ℱ) ⟶ X  lokaler Homöo.
Ende

Lokal → Global

Eine Garbe ist die Grammatik des Übergangs vom Kleinen zum Großen. Keime, Halme, Schnitte, Verkleben — ein einziger Gedanke.
