Ist der Gedankenraum eines
Sprachmodells glatt?

Fast jede KI-Arbeit nimmt stillschweigend an: Die „Gedanken" eines Modells liegen auf einer glatten, gekrümmten Fläche (einer Mannigfaltigkeit). Eine neue Arbeit baut einen Test dafür — und findet: Bei echten Sprachmodellen ist das falsch. Der Raum hat Bruchkanten. Und genau deshalb reagiert ein Sprachmodell manchmal so wild auf beinahe identische Prompts.

3 kleine Experimente 0 Formeln zum Rechnen 4 echte Modelle getestet

1Experiment: zwei gleiche Prompts, zwei Antworten

Das Ausgangsproblem: Ein Sprachmodell antwortet manchmal auf zwei beinahe gleiche Prompts völlig unterschiedlich. Die Hypothese des Papers: Manche Wörter liegen an einer Bruchkante im Gedankenraum. Verschiebt man den Prompt nur ein bisschen, „springt" die Antwort in eine ganz andere Ecke — die Antwort-Wolke zerfällt in getrennte Häufchen.

Was du siehst: Solange das Wort an einer „glatten" Stelle liegt, bleibt die Antwortwolke zusammen. Liegt es an einer Bruchkante, spaltet sie sich auf — das Modell ist dort „blind". Das ist die Prompt-Fragilität, die man im Alltag spürt.

2Experiment: glatte Fläche oder Bruchkante?

Was heißt „glatte Fläche" (Mannigfaltigkeit)? Die Regel ist einfach: Zoom in an jeden Punkt. Wenn das kleine Umfeld wie eine flache Scheibe aussieht, ist die Stelle glatt. Ist es an einer Stelle nicht flach — eine Spitze, eine Einschnürung, ein plötzlicher Richtungswechsel — ist das eine Singularität (eine Bruchkante).

3Der Trick: Dimension = Steigung

Wie misst man so etwas objektiv? Der Kerntrick des Papers: Zähl, wie viele Nachbarn in einem Kreis um einen Punkt liegen (das ist das „Volumen"). In einem d-dimensionalen Raum wächst das Volumen wie rd. Trägst du das im Doppel-Logarithmus auf, ist die Steigung die Dimension.

Volumen(r) ≈ K · rd   ⟹   Steigung im Log-Log-Plot = d

Glatter Raum = die Steigung bleibt gleich (oder fällt sanft). Aber wenn die Steigung plötzlich steigt, ist da eine Bruchkante — das ist das Warnsignal des Tests.

4Was sie an echten Modellen gemessen haben

Die Autoren haben den Test an vier echten Sprachmodellen durchgezogen (je 12 Stunden Rechenzeit pro Modell, fast alles für die Distanzmatrix). Das Ergebnis ist eindeutig:

3 / 4

Bei GPT2 zeigt die Verteilung der Dimensionen drei Gipfel: etwa 20 (Zahlen, Monate, Wochentage), etwa 389 (einzelne Wörter), etwa 531 (meist Wortfragmente). Es gibt sogar Wörter mit Dimension 0 — isolierte Punkte, die im Gedankenraum unendlich weit von allem anderen entfernt sind.

5Warum das wichtig ist

  • Prompts sind nicht portabel: Zwei Modelle mit demselben Wörterbuch (Llemma7B und Mistral7B, beide 32 016 Tokens) haben völlig andere Geometrien (Median-Dimension 4096 vs. 48). Was bei dem einen „glatt" ist, ist beim anderen eine Bruchkante.
  • Kontext heilt nicht: Ein längeres Kontext-Fenster „verwischt" die Singularitäten nicht weg — für jedes Fenster gibt es ein längeres, an dem sie wieder auftauchen.
  • Singularitäten erreichen die Ausgabe: Unter bestimmten Bedingungen bleiben die Bruchkanten auch im Output erhalten.

6Die Grenzen (honesty corner)

  • Keine Verwerfung heißt nichts: „Der Test meldet nichts" ist kein Beweis, dass es glatt ist (z. B. Pythia6.9B). Nur eine Verwerfung ist eine Aussage.
  • Verwerfung sagt nicht, welche Bruchkante: Spitze? Einschnürung? Dimensionssprung? Der Test meldet es, aber nicht die Art.
  • Die zentrale Limitation: Der Test ist nur für Radien unterhalb des „Reach" gültig — und der Reach ist schwer zu schätzen.
  • Randpunkte werden übersehen: Die einzige bekannte Schwäche — Sensitivität kostet Spezifität, offen berichtet.
