Algebraische Geometrie

1Topologische Räume

Intuition: Ein topologischer Raum ist eine Menge von Punkten, bei der wir sagen können: „diese Punkte gehören zusammen (offen)" oder „diese Punkte bilden einen Rand (abgeschlossen)". Es ist die minimale Struktur, um von Nähe und Stetigkeit zu sprechen — ohne Maß oder Winkel.
Formal: Ein topologischer Raum ist eine Menge X mit einem System 𝒜 abgeschlossener Teilmengen, sodass: (1) endliche Vereinigungen abgeschlossen sind, (2) beliebige Durchschnitte abgeschlossen sind, (3) X und ∅ abgeschlossen sind. Die Komplemente heißen offene Mengen.

🎨 Bewege die Maus über den Raum — der Punkt zeigt dir, in welchen offenen Mengen er liegt.

2Irreduzibilität & Noethersche Räume

Intuition: Ein Raum ist irreduzibel, wenn er nicht in zwei kleinere, echte Stücke zerlegt werden kann. Wie ein einzelnes Puzzleteil, das man nicht ohne Bruch weiter teilen kann. Noethersch heißt: jede absteigende Kette von abgeschlossenen Teilmengen wird irgendwann stabil.
Formal: Y ist irreduzibel, falls Y = Y₁ ∪ Y₂ (beide abgeschlossen) impliziert Y = Y₁ oder Y = Y₂. Ein noetherscher Raum lässt sich eindeutig zerlegen: Y = Y₁ ∪ ... ∪ Yₙ in irreduzible Komponenten.

3Prägarben

Intuition: Eine Prägarbe ordnet jeder offenen Menge U eine abelsche Gruppe G(U) zu — stell dir vor: „alle stetigen Funktionen auf U". Wenn V ⊂ U, können wir jede Funktion auf U auf V einschränken. Das ist die Restriktion.
Formal: G: U ↦ G(U) mit Restriktionen res(V,U): G(V) → G(U) für U ⊂ V, sodass: (i) G(∅)=0, (ii) res(U,U)=id, (iii) Restriktionen komponieren transitiv.

Die Funktion auf U (groß) wird auf V (klein) restringiert. Beobachte: nur der ausgewählte Teil bleibt.

4Garben — das Verklebungsaxiom

Intuition: Eine Garbe ist eine Prägarbe mit einer magischen Eigenschaft: lokale Daten, die auf Überlappungen übereinstimmen, kann man immer zu globalen Daten verkleben. Wie ein Puzzle, das sich immer zusammensetzen lässt, wenn die Kanten passen!
Axiome: Für V = ⋃ Vᵢ:
G1 (Trennung): Wenn s|Vᵢ = 0 für alle i, dann s = 0.
G2 (Verklebung): Schnitte sᵢ ∈ G(Vᵢ), die auf Vᵢ ∩ Vⱼ übereinstimmen, lassen sich zu einem globalen s ∈ G(V) verkleben.

Wenn Kompatibilität = 100%, entsteht eine glatte globale Funktion. Sonst „bricht" sie im Überlappungsbereich.

5Halme (Stalks)

Intuition: Der Halm Fₓ in einem Punkt x ist das „infinitesimale Verhalten" der Garbe bei x. Für holomorphe Funktionen: die Taylorreihe! Zwei Schnitte sind gleich im Halm, wenn sie in einer beliebig kleinen Umgebung übereinstimmen.
Formal: Fₓ = colimU∋x F(U) — der direkte Limes über alle offenen Umgebungen von x. Zwei Paare (U,s), (V,t) sind äquivalent, wenn es W ⊂ U∩V gibt mit s|W = t|W.

Wir zoomen zum Punkt x. Immer kleinere Umgebungen — im Limes: der Halm.

6Vergarbung (F⁺)

Intuition: Nicht jede Prägarbe ist eine Garbe. Die Vergarbung F⁺ ist die „kleinste Garbe", die aus F gemacht werden kann — indem man erlaubt, lokale Daten zu verkleben. Halme bleiben dabei gleich!
Konstruktion: F⁺(V) = Funktionen s: V → ⋃ Fₓ, die (1) den Wert s(x) ∈ Fₓ haben und (2) lokal von echten Schnitten repräsentiert werden. Universelle Eigenschaft: jeder Morphismus F → G (G Garbe) faktorisiert eindeutig durch F⁺.

Links: Prägarbe hat „Lücken" — inkonsistente lokale Daten. Rechts: nach Vergarbung nahtlos verklebt.

7Exakte Sequenzen

Intuition: Eine Sequenz A → B → C ist exakt, wenn das „was von A nach B kommt" (Bild) genau das ist, „was in B stirbt beim Weg nach C" (Kern). Wie ein perfekter Datenstrom ohne Verlust und ohne Rauschen.
Formal: A →ᶠ B →ᵍ C exakt bei B ⟺ Bild(f) = Kern(g). Eine kurze exakte Sequenz 0 → A → B → C → 0 bedeutet: A injektiv in B, und C = B/A.

Bild(φ) = Kern(ψ) — die Sequenz fließt perfekt.

8Bild, Kern & Kokern von Garbenmorphismen

Intuition: Bei Garben ist etwas Vorsicht geboten! Der Kern eines Garbenmorphismus ist immer eine Garbe — kein Problem. Aber das Bild und der Kokern im naiven Sinn sind oft nur Prägarben. Um echte Garben zu bekommen, müssen wir vergarben!
Beispiel (exp): Auf X = ℂ* ist exp: 𝒪 → 𝒪* surjektiv auf Halmen, aber z ∈ 𝒪*(X) ist nicht global von der Form exp(f) (Umlaufintegral!). Also: Bildnaiv(exp) ist keine Garbe.
Lösung: Bild(φ) := (Bildnaiv(φ))⁺ und Kokern(φ) := (Kokernnaiv(φ))⁺.

Die kurze exakte Sequenz 0 → 2πiℤ → 𝒪 → 𝒪* → 0 auf ℂ*.

9Direktes & Inverses Bild

Intuition: Wenn f: X → Y stetig ist, können wir Garben zwischen X und Y transportieren. Direktes Bild f∗F: „schiebe F von X nach Y", indem du Urbilder betrachtest. Inverses Bild f⁻¹G: „ziehe G von Y nach X zurück".
Definition: (f∗F)(V) = F(f⁻¹(V)) für V ⊂ Y offen.
(f⁻¹G)ₓ = G_{f(x)} auf Halmen.
Adjunktion: Hom(f⁻¹G, F) ≅ Hom(G, f∗F).

Beobachte, wie Schnitte zwischen den Räumen X und Y transportiert werden.

10Garbenkohomologie

Intuition: Kohomologie misst „was global fehlschlägt, obwohl es lokal klappt". H⁰(X, G) = G(X) sind die globalen Schnitte. H¹(X, G) misst die Obstruktion, lokale Lösungen zu globalen zu verkleben. Höhere Hⁱ messen tiefere Verklebungshindernisse.
Definition: Wähle injektive Auflösung 0 → G → I⁰ → I¹ → ..., dann
Hⁱ(X, G) = Hⁱ(Γ(X, I•)).
Zu jeder kurzen exakten Sequenz 0 → F → G → H → 0 gehört eine lange exakte Kohomologiesequenz.

11Spec(R) — Ringe werden Räume

Intuition: Das ist die zentrale Idee! Jeder Ring R wird ein geometrischer Raum: die Punkte sind die Primideale von R. Ein Ringelement f ∈ R wird zur „Funktion" auf Spec(R): f(x) = f mod pₓ. Algebra ↔ Geometrie!
Definition: Spec(R) = {p ⊂ R | p Primideal}.
Ein Ringhomomorphismus φ: R → R' induziert stetige Abbildung Spec(φ): Spec(R') → Spec(R), p ↦ φ⁻¹(p).
Funktor: Ringop → Top.

Jeder Punkt ist ein Primideal. Der generische Punkt (0) liegt „überall dicht".

12Zariski-Topologie

Intuition: Die Topologie auf Spec(R) ist seltsam: abgeschlossene Mengen sind Nullstellenmengen von Idealen. Sie ist sehr grob — jede nichtleere offene Menge ist riesig. Basis der offenen Mengen: Xf = {p | f ∉ p}.
Abgeschlossen: Z(I) = {p ∈ Spec(R) | I ⊂ p} für Ideale I ⊂ R.
Basisoffen: Xf = Spec(R) \ Z(f) = Spec(Rf).
Quasikompaktheit: Spec(R) ist immer quasikompakt!

Die abgeschlossene Menge Z(f) sind alle Punkte, wo f verschwindet.

13Lokalisierung

Intuition: Lokalisierung ist wie „Zoomen" in der Algebra. Bei Rf machst du f invertierbar — geometrisch entfernst du den Nullstellenort von f. Bei R_p (lokal bei einem Primideal) betrachtest du nur, was „nahe bei p" passiert.
Definition: S⁻¹R = {r/s | s ∈ S}/≡, wobei S multiplikativ abgeschlossen ist.
Spec-Interpretation: Spec(Rf) ↪ Spec(R) ist offene Immersion auf Xf.
Lokal: Rp = (R\p)⁻¹R ist lokaler Ring mit maximalem Ideal p·Rp.

14Schemata — die volle Verallgemeinerung

Intuition: Ein Schema ist ein lokal geringter Raum, der lokal aussieht wie Spec(R). Wie eine Mannigfaltigkeit lokal wie ℝⁿ aussieht! Schemata verkleben affine Stücke (Spec(R)) zu größeren geometrischen Objekten.
Definition: Ein Schema (X, 𝒪_X) ist ein lokal geringter Raum, der eine offene Überdeckung X = ⋃ Xᵢ besitzt, sodass jedes (Xᵢ, 𝒪_X|Xᵢ) ≅ Spec(Rᵢ).
Kategorie: Affine Schemata ↔ Ringe (anti-äquivalent).

Affine Karten Spec(Rᵢ) werden auf Überlappungen zusammengeklebt.

15Quasikohärente Garben

Intuition: Quasikohärente Garben sind das „richtige" Konzept von Modulgarbe auf Schemata. Lokal (auf einer affinen Karte Spec(R)) entsprechen sie einfach R-Moduln M via S(M). Sie sind die algebraisch-geometrischen Analoga von Vektorbündeln.
Definition: Garbe M auf X ist quasikohärent, wenn eine affine Überdeckung Xᵢ = Spec(Rᵢ) existiert mit M|Xᵢ ≅ S(Mᵢ) für Rᵢ-Moduln Mᵢ.
Kohärent: zusätzlich alle Mᵢ endlich erzeugt.
Kategorie: Auf affinem X: QX ≅ Mod(R).

Jede Faser ist ein R-Modul, das sich stetig ändert.

16Proj(S) — projektive Konstruktion

Intuition: Für einen graduierten Ring S = ⊕Sᵢ ist Proj(S) das Analogon zu Spec, aber für „homogene" Daten. Punkte sind homogene Primideale, die S_{>0} nicht umfassen. So bekommen wir projektive Räume statt affiner!
Definition: Proj(S) = {℘ ⊂ S | ℘ homogenes Primideal, ℘ ⊉ S_{>0}}.
Standardkarten: Für fᵢ ∈ S₁: X_{fᵢ} ≅ Spec((S_{fᵢ})₀).
Überdeckung: Wenn S₁ = Rf₀ + ... + Rfₙ, dann X = ⋃ X_{fᵢ}.

Proj(S) wird von n+1 affinen Standardkarten überdeckt.

17ℙⁿ — der projektive Raum

Intuition: ℙⁿ_R = Proj(R[X₀,...,Xₙ]). Punkte sind „Geraden durch den Ursprung" in R^{n+1}. Homogene Koordinaten [X₀ : X₁ : ... : Xₙ] — bis auf Skalierung! Der Prototyp aller projektiven Varietäten.
Twist-Garben: Für jedes k ∈ ℤ gibt es ein Linienbündel 𝒪(k) auf ℙⁿ.
Kohomologie: H⁰(ℙⁿ, 𝒪(k)) = R[X₀,...,Xₙ]ₖ (homog. Polynome vom Grad k)
Hⁿ(ℙⁿ, 𝒪(k)) = dual (Serre-Dualität)
Hⁱ = 0 für 0 < i < n.

ℙ² als Menge von Geraden im ℝ³. Twist 𝒪(k) verändert die „Steigung".

18Linienbündel & Picard-Gruppe

Intuition: Ein Linienbündel ist eine lokal freie Garbe vom Rang 1 — stell dir eine „verdrehte Kopie" von 𝒪_X vor, die auf jeder kleinen Umgebung wie 𝒪 aussieht, aber global verdreht sein kann. Die Menge aller solcher Bündel bildet die Picard-Gruppe Pic(X).
Pic(X): Iso-Klassen von Linienbündeln unter ⊗. Einselement: 𝒪_X. Inverses: L∗ = Hom(L, 𝒪_X).
Kartenwechsel: Auf Uᵢ ∩ Uⱼ Isomorphismus ψᵢⱼ ∈ 𝒪_X* mit Kozykel-Bedingung.
Für Kurven: Pic(X) ↔ Divisorenklassen.

Ein Möbiusband ist ein nichttriviales Linienbündel über dem Kreis!

19Chernklassen

Intuition: Chernklassen sind „Invarianten" von Vektorbündeln — sie messen, wie sehr das Bündel „verdreht" ist. c₁ ist die grundlegendste; für Linienbündel ist es die einzige nichttriviale. Sie leben in den graduierten Stücken Gⁱ(X) der K-Theorie.
Definition: cᵢ(E) = γⁱ([E] - rang(E)) mod F^{i+1}K(X) ∈ Gⁱ(X).
Splittingprinzip: Wenn E = L₁ ⊕ ... ⊕ Lₙ, dann sind cᵢ(E) die elementarsymm. Funktionen in c₁(Lⱼ).
Cherncharakter: ch(E) = ∑ exp(c₁(Lⱼ)) = rang(E

c₁(E) — die erste Chernklasse — visualisiert als Verdrehung.

ch(E) = rang(E) + c₁ + ½(c₁² − 2c₂) + ... — der Cherncharakter als Polynom.

20Der Satz von Riemann-Roch

Intuition: Der Höhepunkt! Riemann-Roch verbindet Topologie (Todd-Klassen, Chernklassen) mit Analysis (Eulercharakteristik, Kohomologiedimensionen). Er sagt uns: „Die Kohomologie einer Garbe kann aus rein topologischen Invarianten berechnet werden."
Grothendieck-Riemann-Roch: Für regulär projektiven f: Y → X:
ch(f_K(G)) = f_G(Todd(T_f) · ch(G))
Für Kurven (klassisch): χ(L) = deg(L) + 1 − g_Y
Für Flächen: χ(L) = ½⟨c₁(L),c₁(L)⟩ + ½⟨c₁(L),c₁(T_Y)⟩ + 1/12(c₁²(T_Y)+c₂(T_Y))

Für Kurven: χ(L) = h⁰(L) − h¹(L) = deg(L) + 1 − g. Ein Wunder der Mathematik!
