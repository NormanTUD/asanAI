The Central Idea: Types are Spaces

In classical math, a type is like a set — just a bag of elements. In HoTT, a type is a space: a collection of points that can be connected by paths.

Why this choice? Traditional equality (a=b) is either true or false. But in mathematics we often ask "are these things the same?" and there can be multiple ways they're the same. Treating types as spaces makes this structure visible.[[14]]
💡 Click the canvas to add points. Hover over two points to see a path between them. Each point is an element; each path is an identification (a proof they're equal).

Paths ARE Equalities

Given two points x, y : A, the identity type x = y is the type of paths from x to y.

Why? A "proof that x equals y" is data — a specific way to identify them. Different paths = different proofs. This is proof-relevant mathematics.[[14]]
The reflexivity path refl_x : x = x stays at x — it's the constant path. Move the slider to see how paths can bend and deform continuously.

Groupoid Structure: What You Can Do With Paths

Paths form a groupoid: they have identity, inverse, and composition.

Why these three? Equality should be:
• Reflexive (x=x always) → identity path
• Symmetric (x=y → y=x) → path inverse
• Transitive (x=y, y=z → x=z) → path composition[[14]]

Paths Between Paths (Homotopies)

Two paths p, q : x = y can themselves be equal! A path p = q is a 2-path or homotopy — imagine sliding one path to the other.

Why does this matter? The path p · p⁻¹ isn't literally the constant path — but there's a 2-path deforming it to the constant one. This "weakness up to higher paths" is what makes types ∞-groupoids.[[14]]
The green region is a 2-path — a continuous deformation from path p (red) to path q (blue). Slide to see it fill in!

Transport: Moving Along Paths

If P : A → Type is a family of types indexed by A, and p : x = y, then transport gives us p_* : P(x) → P(y).

Why? If x and y are equal, then anything true about x should be true about y. Transport is how we move a proof/element from the fiber over x to the fiber over y.[[14]] This makes type families into fibrations.
Bottom: the base space A with a path from x to y. Top: fibers P(x) and P(y) sitting over each point. An element in P(x) gets carried along the path to become an element of P(y).

The Circle S¹ and Its Loops

The circle has one point base and one non-trivial loop loop : base = base. The fundamental group is π₁(S¹) = ℤ — winding number![[13]]

Why an integer? Each way of wrapping a loop around the circle counts. Going around once = 1, twice = 2, backward = -1. Loops that "unwind" cancel out. This is topology emerging from pure logic!

Univalence: Equivalent Types are Equal

Voevodsky's insight: (A = B) ≃ (A ≃ B). Two equivalent types can be identified.[[14]]

Why is this revolutionary? In set theory, {0,1} and {true,false} are different sets that happen to be isomorphic. Univalence says: if they're equivalent, treat them as literally equal. Isomorphic structures share all properties — for free.
