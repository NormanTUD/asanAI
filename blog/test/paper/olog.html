🧬 Ontology Logs

Eine visuelle Reise durch die Sprache der Bedeutung — nach David Spivak

💡 Was ist ein Olog?

Ein Ontology Log (Olog) ist eine formale, aber intuitive Methode, um Wissen zu strukturieren. Es basiert auf der Kategorientheorie und wurde von David Spivak am MIT entwickelt.

Ein Olog besteht aus zwei einfachen Zutaten:

  • 🟪 Typen (Objekte) — dargestellt als Boxen mit Substantiven
  • ➡️ Aspekte (Morphismen/Pfeile) — dargestellt als Pfeile mit Verben/Funktionen

📘 Beispiel 1: Ein Mensch und seine Mutter

Das einfachste Olog: Jeder Mensch hat genau eine Mutter (die auch ein Mensch ist).

📜 Die goldenen Regeln von Ologs

Regel 1: Boxen enthalten Substantive

Jede Box beschreibt einen Typ — eine Menge von Dingen. Der Text sollte mit "ein/eine" beginnen: ein Buch, eine Zahl, ein Ereignis.

Regel 2: Pfeile sind Funktionen

Jeder Pfeil f: A → B ordnet jedem Element von A genau ein Element von B zu. Der Text lautet z. B. hat als ....

Regel 3: Der Text muss einen sinnvollen Satz bilden

"ein Mensch hat als Mutter einen Menschen" ✅
"ein Mensch schwimmt ein Auto" ❌

Regel 4: Kompositionen müssen kommutieren

Wenn es zwei Wege von A nach B gibt, müssen beide dasselbe Ergebnis liefern. Diagramme kommutieren!

🔺 Beispiel 2: Kommutatives Diagramm

Jedes Kind hat eine Mutter, jede Mutter ist eine Frau. Also: Jedes Kind hat eine Mutter, die eine Frau ist. Beide Wege führen zum selben Ergebnis!

✅ Diagramm kommutiert: beide Wege liefern dieselbe Frau!

🔁 Warum Kommutativität so wichtig ist

Stell dir vor, du berechnest den Wohnort-Kontinent einer Person auf zwei Wegen:

  • Weg A Person → Adresse → Stadt → Land → Kontinent
  • Weg B Person → Kontinent (direkte Zuordnung)

Damit das Olog korrekt ist, müssen beide Wege dasselbe Ergebnis liefern — für jede Person. Das nennt man ein kommutatives Diagramm.

🧠 Merksatz

„Wenn zwei Pfade zwischen denselben Boxen laufen, müssen sie gleich sein." — David Spivak

🌍 Wo werden Ologs eingesetzt?

  • 🗄️ Datenbank-Design — Ologs sind mächtiger als ER-Diagramme
  • 🧬 Bioinformatik — Modellierung von Genexpression, Proteinnetzwerken
  • 🤖 Wissensgraphen & KI — semantische Repräsentation
  • 🏭 Systems Engineering — komplexe technische Systeme
  • 📚 Wissenschaftskommunikation — präzise Konzeptaustausch
