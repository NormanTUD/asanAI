Drei Geometrien, eine Maschine: Proben → Nichtlinearität → Readout

Fusion aus: r1-022.html ✕ r1-015.html  (Round 2)

1Kernthese der Fusion

Beide R1-Papiere beschreiben dieselbe zweistufige Maschine auf zwei Skalen. r1-015 benennt sie auf der Probe-Ebene: eine lineare Probe pi (affin für ReLU, frequenzbasiert für sin/cos) wird durch eine punktweise Nichtlinearität σ in eine Geometrie (Polyeder / Torus) verwandelt, die ein linearer Ableser ausnutzt — wörtlich „Die Nichtlinearität ist die Maschine.“ r1-022 benennt dieselbe Maschine auf der Layer-Ebene: eine lineare Q·K-Score-Matrix wird durch Softmax in ein normiertes Kraftfeld (Attraktion + „partielle Hemmung“) verwandelt, das den Embedding-Raum in Becken formt, die ein linearer Unembedding-/Nearest-Point-Readout als nächsten Token liest.

Die Fusion: der Transformer ist EINE Maschine — „lineare Probe → σ-Geometrie → linearer Readout“ — mit drei σ und zwei dualen linearen Formen. (i) σ = sin/cos (beschränkt, periodisch) → Torus, relativ (Position). (ii) σ = Softmax (beschränkt, normierend, kompetitiv) → Becken/Kraftfeld, relational (Attention) — r1-022 liefert das dritte Familienmitglied, das r1-015 als „beschränktes Regime“ postulierte, aber nie nannte. (iii) σ = ReLU (unbeschränkt, faltend) → Polyeder, absolut (MLP). Die lineare Form hat zwei unabhängige Achsen: dichtes/diagonales Feature-Mischen (r1-015) und paarweises Token-Mischen (Q·K) (r1-022).

Die Geometrie ist zugleich Regionen (statisch, r1-015) und Becken mit Fluss (dynamisch, r1-022), gelesen durch denselben linearen (Cosine/Dot) Nearest-Point-Readout als nächsten Token. Probe wählt die Relation, σ wählt die Geometrie, der lineare Readout macht daraus einen Token.

2Widersprüche zwischen A (r1-022) und B (r1-015)

Die zwei widersprechen sich nicht direkt (andere Ebenen), aber auf dieselben Designfragen nehmen sie gegenseitig unvereinbare Stellungen ein. Vier konkrete Spannungen:

  • Woher die Geometrie kommt — welches σ ist „die Maschine“. r1-022: Geometrie-Former ist Softmax, zeilenweise über der Q·K-Score-Matrix (pro-zeile normierend, Summe 1, „partielle Hemmung“); ReLU/sin-cos nie genannt. r1-015: Geometrie-Former ist eine punktweise Funktion auf einer Probe (ReLU faltend / sin-cos wickelnd), wörtlich „Die Nichtlinearität ist die Maschine“; Softmax/Attention nie genannt. Inkompatibel: punktweises σ (B) vs. pro-zeile normierendes σ (A); jeder übersieht das zentrale σ des anderen.
  • Absolut/fest vs. relativ/rotationsinvariant. r1-022: Becken sind feste absolute Punkte („der CAPITAL_OF-Attraktor bei (3.5, 3.7)“); Decode ist absoluter Nearest-Point (Cosine zu festem Vokabularpunkt). r1-015: verteidigt ausdrücklich das Relativ: „die Ähnlichkeit zweier Positionen hängt nur vom Abstand ab, nicht von der absoluten Position“; sin/cos: „Hinzufügen ist Rotieren“, die absolute Position wird gezielt verworfen. Inkompatibel: feste absolute Becken + absolutes Decode (A) vs. relative/rotationsinvariante Kodierung (B).
  • Form des linearen Schritts — Mischen vs. paarweise (ohne Mischen). r1-015: linearer Schritt ist eine volle Matrix („jede Dimension mischt in jede versteckte Einheit“), diagonal = Spezialfall; Mischen verleiht Ausdruckskraft (Regionenzahl = Kraft). r1-022: linearer Schritt ist das paarweise bilineare Q·K — Tokens werden nicht in einen Vektor gemischt, jede Query dotet separat, Values = pro-zeile gewichtete Mittel. Inkompatibel: Schritt mischt alle Dimensionen (A) vs. hält Tokens getrennt und paart sie nur (B).
  • Wofür der Raum gut ist — ein Ort vs. eine Relation. r1-022: der Raum ist ein Ort, in dem Tokens leben und sich bewegen (dynamisch/räumlich); Zweck ist, wo der letzte Token landet → Decode auf einen Token. r1-015: der Raum ist ein Merkmalsraum für Berechnung (funktional); Zweck ist, welche Relation ein linearer Ableser liest; Regionenzahl = Ausdruckskraft. Inkompatible Ontologie: Punkte, die in Becken fallen (A) vs. Koordinaten, die Relationen berechenbar machen (B).

3Auflösung

(1) Softmax ist das dritte punktweise σ in Bs Familie. Bs Dichotomie (unbeschränktes ReLU vs. beschränktes sin/cos) erhält von A ein natürliches Mitglied: Softmax = beschränkt + normierend + kompetitiv. Es wirkt auf einen Vektor linearer Scores wie sin/cos auf eine Probe und erzeugt eine Verteilung (die Geometrie). Einheitlich: ReLU → Polyeder (absolut), sin/cos → Torus (relativ), Softmax → Becken/Kraftfeld (relational). As „partielle Hemmung = relativer Verlust“ ist genau die Beschränktheit + Normalisierung, die B vom beschränkten Regime verlangt. Fused: eine Regel („σ wählt die Geometrie“) mit drei σs.

(2) Absolut vs. relativ → verschiedene Stufen (Bs eigene Stufungs-Methode, auf A angewandt). Die relative Geometrie (sin/cos) regelt, wie Tokens positional aligniert sind — genau das, was das Q·K-Skalarprodukt als relative Ausrichtung liest; die absolute Geometrie (Becken) ist, wo Inhalt/Bedeutung sitzt und gelesen wird. Fused: relativ = Alignment-Achse, absolut = Decode-Achse; ein Transformer nutzt beides auf verschiedenen Stufen.

(3) Mischen vs. paarweise → duale lineare Formen. Bs volle Matrix mischt innerhalb eines Token-Funktionsvektors (über versteckte Einheiten); As Q·K mischt über Tokens hinweg für eine feste Feature (eine Query gegen viele Keys) — dual: Feature-Mischen (dicht) vs. Token-Mischen (Attention). „Diagonal ist Spezialfall von dicht“ verallgemeinert: Q·K spezialisiert das dichte durch Beschränkung auf „gleiche Feature, über Tokens hinweg“. Fused: der lineare Schritt hat zwei unabhängige Achsen; ein voller Layer macht beides (MLP + Attention).

(4) Ort vs. Relation → dasselbe Objekt aus zwei Achsen. Ein Becken (A) ist exakt eine Region (B) — die Menge von Punkten, die ein linearer Readout auf dieselbe Ausgabe abbildet. B benennt die Region (statisch, wo), A den Fluss in die Region (dynamisch, wie/wann, über Tiefe × Köpfe). Fused: Geometrie = Regionen (B); das Attention-Kraftfeld = die Dynamik, die Tokens in sie routet (A); der Readout (Bs Ableser / As Unembedding) ist derselbe Cosine/Dot Nearest-Point.

Fused conclusion: eine Maschine — „lineare Probe → σ-Geometrie → linearer Readout“ — auf drei Skalen mit drei σs (sin/cos relativ, Softmax relational, ReLU absolut) und zwei dualen linearen Formen; die Geometrie ist zugleich Regionen (statisch) und Becken mit Fluss (dynamisch), gelesen durch denselben Nearest-Point als nächsten Token.

4Fusionierter Inhalt

(a) Das einheitliche Rezept. Gegeben ein Signal s, eine lineare Probenfamilie pi(s) und eine punktweise Nichtlinearität σ:

rep(s) = σ( p(s) ) , out = readout( rep(s) )
lineare Form: (i) diagonal/frequenzbasiert (positionell) · (ii) dicht/affin (MLP) · (iii) paarweise/bilinear (Q·K)
σ: ReLU (unbeschränkt → Polyeder, absolut) · sin/cos (beschränkt → Torus, relativ) · Softmax (beschränkt-normierend → Becken, relational)
readout: linear (dicht / Dot / Cosine-Nearest-Point)

(b) Positionell — sin/cos (Seite B): Frequenzen, Torus, Relativität.

PE(pos, 2i) = sin(pos·λi) ,  PE(pos, 2i+1) = cos(pos·λi) ,  λi = 10000−2i/d
  • Skalenhierarchie: λi läuft von ≈1 (schnell) bis ≈1e-4 (langsam) — rund vier Größenordnungen; die langsamste Probe braucht tausende für eine Umdrehung → darüber Aliasing.
  • Torus: sin(λi pos), cos(λi pos) läuft den Einheitskreis ab; die Gesamteinbettung lebt auf einem d/2-dimensionalen Torus (glatt, gekrümmt, periodisch, ohne Knicke).
  • Relativität: ⟨PE(a),PE(b)⟩ = Σi cos((a−b)λi) — hängt nur vom Offset a−b ab. Äquivalent: PE(pos+k) = Mk·PE(pos) mit Rotationsmatrix Mk pro Frequenz — Hinzufügen ist Rotieren.
  • Interferenz: die Superposition aller Frequenzen erzeugt ein einzigartiges Interferenzmuster (Fingerabdruck) pro Position.

(c) MLP — ReLU (Seite B, „dicht“): Faltung, Regionen, stückweise linear.

y = A1·x + b1 ,  z = ReLU(y) ,  out = A2·z + b2
  • Kompositionsargument: ohne ReLU wäre A2(A1x+b1)+b2 = (A2A1)x + (A2b1+b2) — eine einzige affine Abbildung. Das ReLU macht sie nicht-affin → stückweise linear.
  • Regionen: jede versteckte Einheit j definiert eine Hyperebene yj=0; das Vorzeichenmuster zerteilt den Raum in konvexe polyedrische Regionen; innerhalb einer Region ist jede Einheit fest linear oder null → das Netz ist dort affin. Regionenzahl = Ausdruckskraft (Obere Schranke 2-Schicht, n versteckt, in &mathbb;Rd: O(nd)).
  • ReLU-Eigenschaften: homogen (ReLU(λx)=λReLU(x), λ>0), stückweise-linear, dünn (in 1D die Hälfte 0), faltet den Raum entlang yj=0.

(d) Attention — Softmax (Seite A): normiertes Kraftfeld, Becken.

aij = softmax( qi·KT / √d ) (pro Zeile) ,  Kraft: Fij ∝ aij ,  Normalisierung: Σj aij = 1 ,  Becken = Gleichgewicht: Σj Fij = 0
  • Softmax als Geometrie-Former: die paarweisen linearen Scores (Q·K) werden zeilenweise zu einer Verteilung; der resultierende normierte Kraftfeld bildet die Becken. „Partielle Hemmung“ = Normalisierung: mehr Gewicht auf einen Key = relativer Verlust auf alle anderen (Anziehung und Hemmung zugleich).
  • Becken = Regionen: ein Attraktor ist die Stelle, an der die Summe aller Q·K-Kräfte null wird — das Gleichgewicht des Feldes, d.h. die Region, in die ein Token fällt und die ein linearer Readout auf dasselbe Bild abbildet.
  • Organisation: Köpfe parallelisieren das Feld pro Layer (Positional/Syntactic/Semantic); die Tiefe stuft die Absolute-Natur — früh fixiert (POS/Syntax), mittel semantisch, spät dynamisch/kontextabhängig („die sich verlängernde Uhr“).

(e) Readout (beide Seiten): ein linearer Nearest-Point.

ẑ = argminv  ‖ hlast − ev ‖   ⇔   cos(hlast, ev) maximal   (Cosine = normiertes Dot-Produkt — dieselbe q/k-Geometrie)
  • As Unembedding (nächster Vokabularpunkt) und Bs linearer Ableser (welche Region / welcher Offset) sind derselbe lineare Dot/Cos-Vorgang, der eine σ-geometrie auf ein einzelnes Element liest — in A ein Token, in B eine Relation.

(f) Das fusionierte Gefüge (fused architecture).

[Position] → diagonale Frequenzproben × sin/cos = torische, relativ-empfindliche Einbettung (B)
→ [pro Layer: paarweises Q·K × Softmax = Becken / normiertes Kraftfeld, relational (A)]
→ [dichte affine Probe × ReLU = polyedrischer, absoluter Approximator (B)]
→ linearer Unembedding (Cosine-Nearest-Point) = nächster Token

B kodiert (Position, relativ), Attention aligniert (relational, über Tokens), MLP entscheidet (absolut, über Features), der Readout decodiert (linear). Das ist exakt Transformer (PE + Attention + MLP) und exakt CNN/MLP (Features + ReLU-Blöcke).

(g) Faustregel (fused design rule). Wähle das σ nach der Beziehung, die du berechenbar machen willst: relative/periodische → sin/cos (beschränkt·periodisch·torisch); relationale/kompetitive → Softmax (beschränkt·normierend·Becken); absolute stückweise Entscheidung → ReLU (unbeschränkt·faltend·polyedrisch). Wähle den linearen Schritt nach dem Mischungsbedarf: feste, handverlesene Frequenzen → diagonal; erlernte Feature-Kombinationen → dicht; Cross-Token-Alignment → paarweises Q·K. Ein voller Layer stapelt alle drei.
