Diffeomorphismen der Aufmerksamkeit

Fusion aus: fibrebundle4.html ✕ transformer_rein_geometrisch3.html

Kernthese der Fusion

Der Transformer ist kein Stapel intransparenter statistischer Lookups, sondern eine Folge glatter, lokal invertibler Verformungen — Diffeomorphismen — einer Mannigfaltigkeit von Repräsentationen. Jede Schicht ist die Identität (der Residual- bzw. Skip-Stream, in A die aufsteigende „Elektrizität“) plus ein glattes lokales Verschiebungsfeld, das die Aufmerksamkeit erzeugt. Aufmerksamkeit selbst verschmilzt zwei Operationen: (i) eine lineare Projektion der Token-Query-Ausrichtung auf eine Richtung — in B das „Lot auf die Query-Richtung fällen“, per Softmax zu einem Wahrscheinlichkeits-Simplex gemacht — und (ii) eine Konvexkombination von Value-Punkten, die das Token residuell zu einem Bedeutungs-Schwerpunkt zieht; lokal ist genau das eine diffeomorphe Verformung der Mannigfaltigkeit (das „Liquify“ in A).

Das Residual-Glied ist das Scharnier: Es macht aus der nicht-invertiblen Kontraktion der Aufmerksamkeit (B) eine invertible Diffeomorphismus-Schicht (A). Ein einzelner Attention-Kopf verschiebt einen Punkt zu einem Schwerpunkt; N Schichten komponieren N Diffeomorphismen zu einem glatten Pfad entlang der Residual-Säule. A liefert damit die Geometrie zwischen den Schichten (Mannigfaltigkeit, Residual-Säule, tiefe Komposition), B die Geometrie innerhalb einer Schicht (Projektion, Softmax, Bewegung zum Schwerpunkt) — dieselbe Geschichte auf zwei Skalen.

Widersprüche zwischen A und B

Die beiden Papiere stehen sich an drei konkreten Punkten gegenüber:

1. Invertierbarkeit

A modelliert jede Schicht als Diffeomorphismus — eine glatte, invertible Verformung der ganzen Mannigfaltigkeit (Titel „Diffeomorphic Manifold Stack“, Code-Kommentar „Warp the grid (Diffeomorphismus)“). B beschreibt den Einzelschritt der Aufmerksamkeit dagegen als Konvexkombination zum Schwerpunkt („neu = a₁·P₁ + a₂·P₂ + a₃·P₃“, „‚Bank‘ rutscht zum Schwerpunkt“). Eine Mittelbildung ist eine Many-to-one-Kontraktion und damit per Definition nicht invertibel. Widerspruch: Kann dieselbe Schicht eine invertible Verformung (A) und zugleich ein kollabierendes Mittel (B) sein? A's eigener Index-Autor merkt selbst an, dass die Invertierbarkeits-These „eine visuelle Metapher“ ist, da echte Aufmerksamkeit im Allgemeinen nicht invertibel ist.

2. Was bewegt sich?

In B bewegt sich der Punkt: das Wort „Bank“ wandert durch einen festen Raum zum Schwerpunkt. In A verformt sich der Raum: das Gitter wird „liquified“/gebeugt, während die Tokens als Signal gerade die vertikalen Residual-Röhren emporsteigen. Widerspruch: den Punkt im festen Raum bewegen (B) — oder den Raum um den Punkt verzerren (A)?

3. Form des Operators

In B ist Aufmerksamkeit eine lineare Projektion auf eine Query-Richtung (Lot fällen, Projektionslänge = rohes Logit, Softmax = Gewicht). In A ist die Verformung lokal, nichtlinear und abklingend — ein Gauß-Kern um den Fokuspunkt (Code: force = exp(−dist·0.5)·1.2). Widerspruch: linear/projektional (B) vs. lokaler nichtlinearer Kernel (A).

Auflösung

Alle drei Spannungen lösen sich an derselben Struktur auf: dem Residual-Glied x → x + f(x).

  • Kontraktion + Identität = Diffeomorphismus. B isoliert das Verschiebungsfeld f(x) = Σ aᵣ(Vᵣ − x) — die Kontraktion zum Schwerpunkt. A sieht die ganze Abbildung x + f(x). Ist f lokal klein (Kontraktion, ‖Df‖ < 1), so ist x + f(x) ein Diffeomorphismus (Inverse per Kontraktionssatz). Der Residual-Stream (A's „Elektrizität“) liefert exakt den Identitätsterm, der das Kompositum invertierbar macht. Fusionierte Schlussfolgerung: Schicht = Identität (Residuum) + glattes lokales Verschiebungsfeld (Achtung) = Diffeomorphismus der Repräsentations-Mannigfaltigkeit. B zeigt das „Ziehen“, A die daraus folgende invertible Verformung.
  • Aktive vs. passive Diffeomorphismus. Einen Punkt im festen Koordinatensystem bewegen (B) und das Koordinatengitter verzerren (A) sind dieselbe Abbildung, nur aktiv (B) bzw. passiv (A) beschrieben. Man nutzt Punkt-Bewegung, um die Eindeutigung zu erklären, und Raum-Verzerrung, um die globale Wirkung der Schicht zu zeigen.
  • Linear in den Gewichten, lokal-nichtlinear in der Verschiebung. Das Query-Key-Innprodukt ist tatsächlich eine lineare Projektion (B hat mit dem Logit recht). Aber der geometrische Fußabdruck eines Attention-Kopfs auf der Mannigfaltigkeit — Σ aᵣ(Vᵣ − x) mit Softmax-Gewichten — ist eine lokale, glatte, beschränkte Verformung (A hat mit der Gestalt recht). Fusion: die Algebra der Gewichte ist linear/projektional, die Geometrie der Verschiebung ist lokal und nichtlinear; der Softmax macht aus Projektionslängen einen glatten, lokal begrenzten „Stoß“.

Fusionierter Inhalt

Die Geometrie der Aufmerksamkeit (aus B). Wörter sind Punkte im Raum; Bedeutung = Nähe. Ein mehrdeutiges Wort liegt zwischen seinen Bedeutungen: „Bank“ exakt in der Mitte von Sitzbank und Geldhaus. Eine Query ist eine Richtung R (in B: R = normalize(e᷃ᵌ᷃ − eᵘᵡᵣ–)). Die Passung eines Tokens wird gemessen, indem man das Lot auf R fällt und die Projektionslänge liest — das rohe Logit. Softmap macht daraus ein Wahrscheinlichkeits-Simplex Σ aᵣ = 1 (Temperatur ε: klein = scharf, groß = breit; negative Projektionen gewichten ein Wort herunter, in B rot). Die Values sind hier die Punkte selbst, also ist das Ergebnis die Konvexkombination neu = Σ aᵣ eᵣ — das Wort rutscht zum Schwerpunkt und damit zu der Bedeutung, die der Kontext stützt. Das ist die gesamte Eindeutigung in einem Schritt.

Die Geometrie der Schicht (aus A). Jede Schicht ist ein glattes, invertibles Beugen (Diffeomorphismus) einer Repräsentations-Mannigfaltigkeit; Schichten stapeln sich vertikal. Der Residual-Stream ist die vertikale „Elektrizität“, die das Token-Signal durch alle Schichten trägt — der Identitätsterm. Der Attention-Fokus (in A: die Maus) verformt das Gitter lokal über einen abklingenden Kernel. Tiefe = Komposition dieser Schicht-Diffeomorphismen: ein Token beschreibt einen glatten Pfad.

Die Verschmelzung. B ist der Spezialfall Values = Positionen, in dem „zum Schwerpunkt wandern“ wörtlich stimmt. Im Allgemeinen sind die Values eine eigene lineare Karte (V = XWV), also ist das Ergebnis der Aufmerksamkeit kein Punkt auf der Ursprungslinie, sondern ein Verschiebungsvektor. Addiert man diesen residuell (x + f(x)), wird daraus die lokale diffeomorphe Verformung, die A zeichnet. A's „Elektrizität“ ist damit die Identität, und die „Beugung“ ist das f(x) der Aufmerksamkeit. Eindeutigung (B) ist ein Diffeomorphismus; Tiefe (A) ist die Komposition vieler.
