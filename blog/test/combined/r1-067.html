Token-Fokus: Die lesbare Reise durch den chaotischen Raum

Fusion aus: youarellm2.html × paperidea3.html

Kernthese der Fusion

Beide Papiere fragen nach demselben, aber von zwei Seiten her: Was bestimmt das Schicksal eines einzelnen Tokens in einem Transformer? youarellm2.html lässt den Leser in das Token schlüpfen und führt es durch eine lesbare, stufenweise Pipeline — Embedding → Positional Encoding → Self-Attention (QKV, kausal) → FFN → Softmax → nächstes Token. Jede Stufe kann man Schritt für Schritt ablesen. paperidea3.html nimmt stattdessen einen Punkt im Embedding-Raum und zeigt, wie seine Position über eine chaotische, invertierbare Abbildung (Arnold-Katzen-Map) bestimmt, welche Regionen eines Bildes scharf sind und welche pixeliert — eine Beziehung, die ausdrücklich »non-obvious« ist und empirisch erforscht werden muss.

Die einheitliche These der Fusion lautet: Das Verhalten eines Tokens wird von seiner Position in einem hochdimensionalen Raum gesteuert, und diese Position→Wirkung-Abbildung ist gleichzeitig (a) lokal lesbar — jede Stufe der Pipeline lässt sich einzeln nachvollziehen — und (b) global chaotisch — kleine Änderungen der Position erzeugen große, nicht unmittelbar vorhersehbare Verschiebungen des Ergebnisses.

Ein Token ist also ein Punkt, der eine interpretierbare Pipeline durchläuft, die jedoch auf einer empfindlichen, chaotischen Geometrie operiert: lokal verständlich, global unvorhersagbar. Die »Reise« (A) und die »Linsencode« (B) sind keine Gegensätze, sondern die Mikro- und Makro-Seite derselben Transformation.

Widersprüche zwischen A und B

1. Lesbarkeit vs. Chaos der Position→Wirkung-Abbildung

A (youarellm2.html): Die Pipeline ist glatt und durchschaubar — »ähnliche Wörter sind nahe bei mir«; man kann jede Stufe (Embedding-Raum, Attention-Heatmap, Softmax-Balken) lesen. Die Geometrie des Embedding-Raums wird als semantisch und interpretierbar vorgestellt.

B (paperidea3.html): Die Abbildung von der Token-Position zur Wirkung ist absichtlich »non-obvious — explore it!«; kleine Verschiebungen können den Fokus dramatisch verschieben. Die Map ist eine chaotische Faltung, die »manchmal springt«.

→ A: die Geometrie ist ein lesbarer, glatter Sinn-Raum. B: dieselbe Art von Abbildung ist ein chaotisches Scramble, das man erforschen, aber nicht ablesen kann.

2. Lineare/positional vs. chaotische Positions-Kodierung

A: Die Position wird additiv und glatt kodiert — sin/cos-Positional-Encodings werden zum Embedding addiert (x = Embedding + PEpos); ein einfaches, lineares, invertierbares Positions-Signal.

B: positioniert sich explizit gegen lineare/positional Kodierung: Positionen sollen statt linearer Kodierung durch eine chaotische, invertierbare Abbildung (Arnold-Katzen-Map) auf eine »Lens«-Karte gehasht werden, die den räumlichen Fokus verteilt.

→ A addiert eine glatte Positions-Kodierung; B ersetzt sie durch eine nichtlineare (wenn auch invertierbare) Faltung.

3. Kausal/asymmetrisch vs. symmetrisch-räumliche Kopplung

A: Aufmerksamkeit ist kausal (Maskierung j ≤ i) — Information fließt streng in eine Richtung (Vergangenheit → Gegenwart).

B: Das »parallel transport« zwischen Stalks ist symmetrisch und räumlich: Gewichte wij = 0,35·exp(−d²/2σ²) nach euklidischer Distanz, bidirektional, ohne Reihenfolge.

→ A koppelt über kausale Ordnung (asymmetrisch), B über räumliche Nähe (symmetrisch).

4. Tiefe: Verfeinerung vs. sich verstärkendes Chaos

A: Tiefere Schichten verfeinern den Vektor sauber; LayerNorm stabilisiert (Mittelwert 0, Varianz 1).

B: »Each layer adds more warping complexity«; warpScale ∝ 1,8l, die Jacobi-Verzerrung »wächst nach unten« — Tiefe = wachsende Nichtlinearität.

Auflösung

Der Kern aller vier Spannungen ist derselbe: der Maßstab. Beide Abbildungen sind deterministisch (A: seeded Matrizen, B: deterministic Chaotic-Hash). Der Widerspruch liegt nicht im Mechanismus, sondern in der Perspektive — lokal vs. global.

Zu 1 & 4 — lesbar im Mikro, chaotisch im Makro

Lesbarkeit ist lokal/stufenweise: jede einzelne Schicht (Embedding, Attention, FFN) kann man nachvollziehen. Chaos ist global/kompositiv: die End-zu-Ende-Map summiert Faltungen und Ähnlichkeitsgewichte über viele Schichten, und genau diese Komposition macht sie empfindlich. Fusionierter Schluss: Man kann jeden Schritt lesen (A), aber wo der Fokus / das nächste Token am Ende landet, ist empfindlich von der Eingabe-Position (B). Tiefe (Punkt 4) ist dann einfach der Prozess, durch den sich diese Empfindlichkeit aufsummiert — pro Schicht lesbar, im Ganzen chaotisch; LayerNorm begrenzt dabei die Drift, ohne die empfindliche Geometrie aufzuheben.

Zu 2 — die additive PE ist der glatte Sonderfall der chaotischen Linsen

Sowohl A's sin/cos-PE als auch B's chaotische Map sind invertierbare Positions-Encodings. A verwendet den glatten, additiven Fall, B den nichtlinearen Fall. Fusion: Eine Positions-Kodierung ist eine (möglicherweise nichtlineare, lernbare, invertierbare) Map von Index+Identität → Punkt. Der Token hat beides: einen Sequenz-Index, der Ordnung/Kausalität trägt (A), und eine Koordinate im Raum, die die räumliche Fokus-Metrik trägt (B). Die additive PE ist der interpretierbare Grenzfall; die chaotische Linsen die expressive Verallgemeinerung — und reale Modelle könnten dazwischen liegen (lernbare, nicht-additive PE).

Zu 3 — kausal (Richtung) + ähnlichkeitsgewichtet (Art des Mischens)

A's Attention mischt über ein Ähnlichkeits-Maß (QKT = Skalarprodukt ≈ negative Distanz) und maskiert kausal. B's Gauß-Distanz-Kopplung ist genau das symmetrische Analogen desselben Ähnlichkeits-Mischens. Fusion: A liefert die asymmetrische Flussrichtung (nur nach links), B liefert die Art des Mischens (nah/ähnlich = stark gekoppelt). Attention = kausal (A) und ähnlichkeits-/distanzgewichtet gemischt (B) — das scheinbar Symmetrische wird durch die kausale Maske in einen gerichteten Fluss geformt.

Ein Token ist ein Punkt in einem hochdimensionalen Raum. Es hat eine Position (Index → Kausalität, glatte PE) und ist eine Position (Koordinate → chaotische Fokus-Metrik). Die Pipeline, die es durchläuft, ist schrittweise lesbar; die Metrik, auf der sie operiert, ist chaotisch. Lokal verständlich — global unvorhersagbar. — Fusionierte Kernposition

Fusionierter Inhalt

Das Token als Punkt

Amb gemeinsame Grundidee: ein Token ist ein Punkt in einem (hoch-)dimensionalen Raum. A: der Punkt ist das Embedding WE[id] ∈ &mathbb;R}d (Einheitskugel, ähnliche Wörter nahe) plus Positions-Fingerabdruck. B: der Punkt ist ein frei platzierbarer »Stalk« im 2D-Raum, dessen Lage die Fokus-Metrik steuert. Die Fusion behält beide: Index für die Rolle, Koordinate für die Kopplung.

Die Pipeline (aus A)

Stufenweise, lesbar — jede eine kleine, nachvollziehbare Transformation:

PE:  PE(pos,2i) = sin( pos / 100002i/d ),  PE(pos,2i+1) = cos( pos / 100002i/d )
    x = Embedding(token) + PEpos

Attention:  Q = xWQ, K = xWK, V = xWV;  Attention(Q,K,V) = softmax( QKT / √dk ) V;  kausal: nur j ≤ i

FFN:  FFN(x) = ReLU(xW1+b1)W2+b2,  W1 ∈ &mathbb;R}d×4d (Flaschenhals)
LayerNorm:  (x − μ) / √(σ²+ε) · γ + β

Output:  logits = h·Wvocab;  P(wi) = softmax(logits / T)i;  Greedy = argmax, Sampling ∼ Categorical(P)

Der chaotische räumliche Aspekt (aus B)

Chaotische Faltung (Arnold-Katzen-Variante):  focus(pos) = Fold( pos &oplus layer_freq ),  zwei Runden sinusoidale Faltung + Wrap mod 1 — »manchmal springt«

Fokus = Scharfe:  f(p) = exp( −d(p, focus)² / (2 r²) ) → scharf nahe, pixeliert fern

Parallel transport:  wij = 0,35·exp( −dij² / (2σ²) ), normalisiert (i=j → 1); residual stream

Warp pro Layer:  warpScale ∝ 1,8l;  Jacobi J = [ ∂u/∂x ∂u/∂y ; ∂v/∂x ∂v/∂y ] — Fokus-Punkte sind fixe Anker, der Raum verformt sich um sie

Sway:  Σ |pos − posdefault| steuert die Intensität

Die Integration — ein einziges Modell

Der entscheidende Schritt der Fusion: A's Softmax über dem Vokabular und B's Fokus-Map über dem Bild sind derselbe Mechanismus. In beiden Fällen erzeugt ein Punkt im Embedding-Raum eine gepuckte Verteilung über einen Ausgaberäum:

  • A: Punkt (finaler Vektor) → Softmax → Wahrscheinlichkeit über Kandidatentokens — »hoch wo attended, niedrig wo nicht«.
  • B: Punkt (chaotisch abgebildet) → Fokus-Glocke → Scharfe über Bildregionen — »scharf wo gefokust, pixeliert wo nicht«.

Der chaotische Fold (B) ist die akkumulierte Empfindlichkeit der End-zu-Ende-Transformation (A's Schichtenkette): er ist der Grund, warum zwei nahe Kontexte unterschiedliche nächste Tokens erzeugen können, auch wenn jede einzelne Schicht lesbar ist. Attention mischt dabei über Ähnlichkeit (A's QKT ≈ B's negative Distanz) mit kausaler Maske (A) — B's symmetrische Distanz-Kopplung ist das ungeformte Vorbild dieses gerichteten Mischens.
