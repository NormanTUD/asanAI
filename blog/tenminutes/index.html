The first ten minutes

A machine that predicts one token at a time.

That is the whole trick. Everything else — chat, code, translation, reasoning — is that one prediction repeated in a loop (Brown et al., 2020), at enormous scale (Hoffmann et al., 2022). The units are tokens, not words: a token can be a whole word, a word fragment, or a piece of punctuation, but the loop is the same (Sennrich et al., 2016). Follow a sentence from text to tokens to probabilities, and watch the loop write.

Field notes

Words that do a lot of work.

Each term opens the lesson where it becomes concrete — no glossary memorisation required.

Next-token predictionA probability distribution over the vocabulary, one selected token, then the loop repeats. Autoregressive loopThe output token is appended to the input and becomes part of the next prediction. TokenA chunk of text with an ID. It is a slot in a fixed vocabulary, not a concept. EmbeddingA token represented as a point in a high-dimensional space; relationships can be directions. Cosine similarityThe angle between two vectors. It measures directional alignment, not magnitude. AttentionA learned routing operation: a query asks, keys answer, values travel. Residual streamThe shared workspace that each sublayer reads and adds its update back into. AgentAn LLM in an observe–reason–act loop with tools, memory, and a permission model.

A note on scope

“A token is not a concept the model knows; it is a slot the model had to fill from data.” Tokenization

The demos are here to build intuition, not to compute a real model. They show the mechanism at a scale you can hold in your head; where a number is illustrative rather than measured, the page says so. “No math” does not mean the idea is simple; it means the page will not make you decode an equation to get it.
