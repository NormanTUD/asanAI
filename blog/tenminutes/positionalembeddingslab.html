Attention is order-blind.

A transformer processes tokens in parallel. Without a position signal, 'dog bites man' and 'man bites dog' would be the same bag of vectors.

01 The missing coordinate

Where is the token?

Attention is order-blind. The missing coordinate is position. Attention compares tokens by content. It has no built-in notion of first, second, or last. Positional encodings add a signature to each token's vector so that the model can tell where it sits in the sequence. You might ask why the model cannot simply use the token's index. An index is unbounded and says nothing about distance: position 1,000 is not “far” in any useful sense unless the model learns a scale. A crafted encoding supplies that scale.

The original transformer used sine and cosine functions at different frequencies (Vaswani et al., 2017). Modern models often use rotary position embeddings (RoPE), which rotate the query and key vectors by an amount that depends on position.

02 Absolute and relative

Distance often matters more.

Some schemes encode absolute position; others encode relative distance. Relative information is often more useful: what matters is not only where a word is, but how far it is from the words it relates to.

The details are mathematical, but the intuition is simple: position turns an unordered set of tokens into a sequence. Without it, the model loses syntax and word order.

03 The geometry of position

A manifold, not just labels.

Sine and cosine at different frequencies create a smooth fingerprint for every position. Nearby positions share low-frequency patterns; distant positions differ in the high-frequency dimensions. The set of position vectors forms a manifold rather than a set of unrelated labels. Why waves? Because a wave is bounded, smooth, and periodic, so every position gets a distinct pattern without the values growing without bound. The different frequencies encode different scales: a slow wave distinguishes the beginning from the end of a long text, while a fast wave distinguishes neighbouring positions.

The denominator is a geometric progression. The slowest pair completes one cycle every positions; each faster pair is a fixed factor quicker. That is why the encoding behaves like a multi-scale clock: coarse hands mark the beginning and end of a long text, fine hands separate neighbouring positions. The scheme is also linear in a precise sense: for a fixed offset , is a fixed linear function of . Attention can therefore learn relative distance without a lookup table.

Modern models often use rotary position embeddings. RoPE (Su et al., 2021) rotates the query and key vectors by an amount that depends on position, so the dot product between them depends on relative distance. That makes relative position easier to learn. Concretely, a query at position m and a key at position n are rotated by angles proportional to m and n; when you take the dot product, the absolute angles cancel and what remains depends on m − n. The model gets “how far apart” almost for free.

The details matter for long context. A model trained on one range of positions may not extrapolate gracefully to a much longer range. Position is a coordinate, and the coordinate system has to fit the data.
