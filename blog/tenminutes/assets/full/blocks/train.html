Dependency: $d_{\text{model}}$ must be a multiple of $h$.
Reason: Multi-head attention splits the main vector into $h$ parallel “viewpoints.” If $d_{\text{model}}$ is 4 and $h$ is 2, each head looks at 2 dimensions.

How many transformer blocks are stacked. More layers allow more abstract reasoning.

128

Effect: Sets the maximum number of tokens the model can “see” at once during training and inference.
Reason: A larger context window lets the model capture longer-range dependencies, but the attention score matrix has size $\text{Context}^2$, so a full forward pass costs quadratically in context length. A KV-Cache avoids recomputing past keys and values during generation — it lowers per-step work and trades it for linear memory — but it does not make attention sub-quadratic.
