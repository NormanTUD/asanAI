01 Before 2017

The problem was the queue.

Recurrent networks read a sequence one step at a time. Information about the beginning had to survive a long chain of updates before it could influence the end. Convolutions could parallelize, but the path between distant tokens still grew with distance.

The transformer made the path length one: every token attends to every other token in a single layer. That is not only a modelling choice; it is a hardware choice. A computation that fills a GPU instead of serializing along the sequence is what made scale practical.

Attention is not a metaphor for looking. It is a learned, differentiable routing operation: a query asks, keys answer, values travel. The core of the architecture

03 The layer lens

A word changes its meaning with depth.

At the input, “bank” is already a vector. Then each block rewrites it. The residual stream carries the old representation forward and adds a new one on top: x → x + Attention(Norm(x)), then y → x + FFN(Norm(x)). Nothing overwrites the past; everything accumulates.

The layer lens below is a deliberately simple story: context pulls the word toward one of two clusters. With “river” in the sentence, “bank” drifts toward the river cluster; with “loan”, toward finance. Drag the layer slider and switch the context. Real trajectories are high-dimensional and much messier; the qualitative idea — context accumulates with depth — is the point.

04 Inside the block

Two sublayers, one residual stream.

Attention mixes information across positions. Feed-forward transforms each position independently: expand to a wider hidden dimension, apply a nonlinearity, contract back. Attention decides what to look at; the FFN decides what to do with it. The FFN is also a major locus of memorized associations and factual patterns, though knowledge is distributed across the network rather than sitting in one place.

Residual connections give the gradient an identity path around each sublayer. Without them, very deep stacks suffer vanishing or exploding gradients. Layer normalization keeps activations in a healthy range. In the 2017 block, normalization sat after the residual addition; modern stacks usually normalize inside the branch (pre-norm), leaving the residual stream unbroken, and often replace LayerNorm with RMSNorm, which rescales by the root mean square without subtracting the mean.

z = x + Attention(Norm(x))
y = z + FeedForward(Norm(z))
Attention(Q,K,V) = softmax(QKT/√dk) V

Decoder only, or encoder too?

BERT kept the encoder and trained bidirectionally with masked tokens; GPT kept the decoder and trained autoregressively with a causal mask. The same block, two contracts with the data.

Multi-headSeveral attention heads run in parallel, each in a lower-dimensional subspace, then concatenate.
Causal maskIn a decoder, token i may only attend to tokens ≤ i. The future is not available.
ResidualThe stream is a highway for information and gradients; each layer adds a small update.
Pre-normNormalizing the branch instead of the stream makes deep stacks easier to train.
05 From vectors to words

Logits, softmax, and the stop token.

The final hidden state of the last token is multiplied by an unembedding matrix, producing a logit for every token in the vocabulary. Softmax turns the logits into a probability distribution. A decoding rule chooses one token: greedy takes the maximum, sampling draws from the distribution, temperature scales the logits, top-k/top-p restrict the pool. The chosen token is appended to the context and the loop runs again.

How does it stop? There is no separate stop detector. The end-of-sequence token is an ordinary vocabulary entry; “stopping” means the distribution puts enough mass on EOS at a natural boundary. Instruction-tuned models also seem to carry a rough plan of the answer’s length, readable from the prompt’s final hidden state before the first output token — but that is a learned estimate, not an odometer.

Common misreading “Attention is all you need, literally.” Attention routes; the FFN computes; residuals carry; normalization stabilizes. Remove any one and the machine changes.
Better frame “The block is a division of labour.” Attention moves information; the FFN transforms it; the residual stream keeps a shared workspace.
Common misreading “The model builds a syntax tree and then reads it.” Syntax is distributed across heads and layers, not stored as one object.
Better frame “Depth builds structure bottom-up.” Lower layers assemble local units; higher layers integrate larger relations.

One last surprise from the full chapter: a trained transformer does not merely predict from its context — a linear attention layer can implement a step of gradient descent on the examples in the prompt. That reframes in-context learning as an optimizer the model learned to run inside its forward pass. The result is suggestive, not a complete explanation; it is one of the most interesting open threads in the field.
