The model only knows what is in the window.

A context window is not a persistent memory. It is the entire input the model can see in one forward pass: system prompt, history, documents, and your new question.

01 A fixed input buffer

Everything competes for space.

Every token in the conversation occupies space in the context window. When the window is full, something has to be dropped, summarised, or moved outside the model. The model does not remember earlier turns unless they are still in the window.

Window sizes have grown from a thousand tokens to hundreds of thousands or more, but bigger is not automatically better. The model still has to find the relevant part, and attention over a long sequence is expensive.

02 Why long context is hard

Attention has a cost.

Self-attention compares every token with every other token, so the cost grows roughly quadratically with length. Techniques such as KV caching and FlashAttention make long context practical, but they do not make the model infinitely attentive.

For knowledge outside the window, systems use retrieval: search a document store and inject the relevant passages. That is why context and RAG are close cousins.

03 Working memory in practice

Long context is not free.

The KV cache stores the keys and values for every token in the context, so the model does not recompute the past at every step. The cache grows with the context length and can dominate memory during long conversations. Serving systems have to manage it carefully.

FlashAttention and other kernels make attention more efficient, but they do not change the fundamental cost. Long-context models also have to learn to use the middle of a long window; information near the start or end is often easier to retrieve.

Retrieval and long context are complementary. A bigger window lets the model see more; retrieval decides what is worth seeing. The budget is still a budget.

Strategy 3: Compaction (Summarize and Continue)

The key insight: memory is always external. The LLM itself is stateless, it's the surrounding system that creates the illusion of continuity by carefully managing what goes into the context window at the start of each interaction. ChatGPT's memory works through a combination of detection of memory-worthy information, storing of such information, and retrieval-augmented generation. In addition to saved memories, it now references all past conversations to deliver responses that feel more relevant and tailored. Four layers working together create the illusion that ChatGPT knows you personally.

What Is a Context Window?

A context window (also called “context length”) is the maximum number of tokens the model can process in a single forward pass. It includes everything: the system prompt, all previous messages in the conversation, any injected documents, and the new query.
