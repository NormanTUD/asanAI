Seeing is layered pattern detection.

A computer does not see a cat. It sees a grid of numbers. Convolution learns small local patterns, and depth combines them into edges, parts, and objects.

01 A filter that slides

Local patterns, shared weights.

A convolution applies a small kernel to every local patch of the image. The kernel is a set of learned weights; it responds strongly to a particular pattern, such as a vertical edge or a patch of colour.

Stack convolutions and the hierarchy grows. Early layers detect edges and textures; middle layers combine them into parts; later layers respond to whole objects. That is the feature hierarchy behind modern vision.

02 From classification to space

The task stack.

The basic task is classification: what is in the image? Detection asks where; segmentation asks which pixels belong to which object; 3D understanding adds depth and geometry. Each task needs a different output, but the feature extractor is often shared.

Vision Transformers replace the sliding kernel with attention over image patches, but the idea is similar: turn the image into tokens and let the model learn relationships between them.
