The model can think longer.

For years, scaling meant training a bigger model. Reasoning models add another axis: give the model more computation at inference time and let it explore, check, and revise.

01 Thinking in the open

Use the context as a scratchpad.

Chain-of-thought prompting asks the model to write intermediate steps instead of jumping to an answer. On arithmetic and logic, this often improves accuracy because the model can use the context as a scratchpad.

Self-consistency samples several reasoning paths and takes the majority answer. Tree of thoughts explores branches and evaluates them. These methods trade more computation for better answers.

02 Learning to reason

More compute, more checking.

The o1/R1 generation goes further: the model is trained with reinforcement learning on problems that can be checked, so it learns when to think longer, backtrack, and verify. The reasoning process can be much longer than the final answer.

More thinking is not always better. The model can reason confidently in the wrong direction, and long chains are expensive. The useful question is whether the extra computation buys a real improvement on the task.

Problem: A bat and a ball cost $1.10. The bat costs $1.00 more than the ball. How much does the ball cost?

Let the ball cost x. Then the bat costs x + $1.00.
x + (x + $1.00) = $1.10.
2x = $0.10, so x = $0.05.
The ball costs $0.05; the bat costs $1.05.

Answer: $0.05.

TakeawayWriting the steps gives the model a scratchpad. More computation can help — but only if the steps are checked.
03 Takeaway

Thinking longer helps when the extra steps can be checked; otherwise it just costs more.
