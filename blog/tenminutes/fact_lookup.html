A fact is a pattern, not a row.

The model has no table called 'countries'. 'Paris' emerges from the interaction of weights, attention, and a residual stream. The picture is partial, and that limit matters.

01 A forward pass, not a lookup

The computation produces the fact.

The prompt becomes tokens, then vectors. Each transformer block reads from a residual stream, lets attention route information between positions, and lets the MLP write an update back into the stream. The final vector is scored against the vocabulary.

The residual stream is a shared scratchpad. Attention can move the meaning of 'France' to the final position; the MLP can act like a learned key-value memory. The fact is distributed across many weights, not stored in one place.

02 What we know and what we do not

Partial maps, real limits.

Mechanistic interpretability has found circuits and directions that correspond to real behaviour, and methods like ROME can edit a fact by changing specific weights. But the full story is not known, even by the people who build the models.

The practical lesson is not that the model has a tidy database. It is that knowledge is entangled with computation, which is why a model can be confident and wrong, and why editing one fact can have side effects.

03 How we know

Circuits, directions, and limits.

Mechanistic interpretability looks for circuits: small sets of attention heads and MLP neurons that implement a behaviour. Induction heads, for example, learn to complete a pattern of the form A B ... A -> B. Finding a circuit is evidence that a behaviour has a specific internal mechanism.

The linear representation hypothesis says that many features are represented as directions in the residual stream. If that is right, you can read a feature by projecting onto a direction, and edit a fact by changing the weights that write it. ROME is one method for doing that.

The picture is still partial. Features can be superposed, neurons can be polysemantic, and editing one fact can have side effects. The defensible claim is not that we understand the model completely; it is that we have partial maps with real evidence.

Background

Facts as directions: the linear representation hypothesis

This is the linear-representation + soft-key-value-memory picture in one breath. It is the picture that most current interpretability researchers are betting on, and it has the strongest convergence between theory (Park et al.'s causal inner product) and experiment (ROME, function vectors, knowledge neurons).

This same "direction with a fixed meaning" scales from facts to whole behaviors. The country→capital relation above is one kind of axis; the Mechanistic Interpretability lesson catalogs others — the truth, refusal, and honesty directions, sentiment and tone axes, and even where-and-when (spatial and temporal) directions — each found and verified the same way.

Background

Watching the answer form: the logit lens

All of the above is the result of careful post-hoc analysis: you run the model, find what mattered, edit it, see what changes. There is also a much simpler trick that lets you watch the answer form in real time as the forward pass progresses: the logit lens.

In a well-trained Transformer, the intermediate residual streams are already approximately in the unembedding basis (this is a consequence of the residual structure, weight decay, and the fact that the model is being trained end-to-end to produce a useful final residual stream). So the logits you get from intermediate layers are a meaningful, if imperfect, readout of "what would the model predict if it had to stop here?".

More background

What the model actually computes, top to bottom

The forward pass that turns "The capital of France is " into a distribution over next tokens is short. In a modern decoder-only Transformer like those behind GPT, Claude, and LLaMA, it looks like this:

  1. The prompt is tokenized and each token is looked up in the embedding table.
  2. A position signal is added, so the model knows where each token sits.
  3. Each block normalizes its input, runs attention across positions, and adds the result back to the stream.
  4. The same block normalizes again, runs the MLP on each position, and adds that result back to the stream.
  5. After the last block, a final normalization produces the residual stream the model will read out.
  6. The last position's vector is multiplied by the unembedding matrix, producing a logit for every vocabulary token; softmax and a decoder turn that into a choice.

Nothing in that list is a lookup of “France → Paris”. The fact has to be reconstructed by the interaction of the weights with this particular context.

More background

The MLP as a soft key-value memory

If attention is the routing layer — the part that figures out which information matters — then the MLP layers are where the content of the model's knowledge actually lives. This is the most important conceptual claim in this chapter, and it has substantial experimental support.

The mechanism is a soft key-value memory. The first matrix, W₁, contains rows that act like keys: each row responds to a pattern in the residual stream. The nonlinearity decides which detections pass, and the second matrix, W₂, writes the corresponding values back. The hidden layer is wide, so many key-value pairs can share it; that is why the memory is distributed and why a fact can be partly present. Nothing is addressed by an exact string. The model retrieves the value whose key best matches the current state.

More background

Opening up one fact: ROME

ROME starts from the hypothesis that a fact is a key-value pair in an MLP. It finds the layer where the subject's key is written, computes a value direction that would produce the new object, and edits the second matrix so that the key writes the new value. The result: after the edit, the model says Rome when asked about the Eiffel Tower, says Rome when asked "Where is the Eiffel Tower?", says Rome when given "Eiffel Tower: ___" — and, crucially, still says Paris when asked about the capital of France. In this example the edit looks local, and the neighbouring fact survives. That is striking, but it is not a guarantee: follow-up work found that such edits can have side effects, and that a fact may not live in a single clean key-value slot. The honest reading is that ROME demonstrates a mechanism, not that models are databases with editable rows.
